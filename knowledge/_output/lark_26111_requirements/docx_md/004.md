# 25MP 超清模式需求文档

## 1. 背景与目标

### 需求背景

当前默认输出4合一12MP，且高像素选项仅提供 50MP。12MP有时无法释放sensor最大解析力，而高像素与hdr算法互斥，成片速度和存储占用大。用户在追求更高解析力的同时，对成片速度和存储占用较为敏感。行业竞品（iPhone、华为、OPPO）已布局中间档位高像素方案，其中 iPhone 将类似能力集成至默认模式，华为支持全焦段/暗光场景。

### 用户痛点/机会点

- 
- 50MP 模式下 shot-to-shot 间隔较长，连拍体验受限，且无法支持hdr等算法
- 用户需要一档"画质优于默认、速度优于 50MP"的中间选项

### 目标用户与场景

- **目标用户**：对画质有进阶要求但不愿牺牲拍摄效率的日常用户
- **核心场景**：

  - 明亮户外/室内环境的主摄/长焦拍摄
  - 静态/慢速运动主体/人像
  - 社交媒体分享前需要更高解析力的场景

### 预期收益

- 提升默认模式高像素档位使用率（替代现有 50MP 成为主力高像素选项）
- 优化 shot-to-shot 性能，改善连拍体验
- 降低单张存储占用 vs 50MP，提升用户可拍摄张数

## 2. 功能定义

### 功能名称

25MP 超清模式（25MP Ultra Clear）

### 功能描述

基于 ArcSoft 25M TurboFusion 算法，通过多帧合成与全分辨率图像的多区域细节分析融合，充分发挥传感器解析力，在性能与画质之间实现平衡，输出最高约2500万像素的高解析力图像，呈现自然、真实、接近光学质感的画面效果，减少计算摄影带来的过度算法感。

### 适用模式/入口--待定

- **入口位置**：相机 >设置>照片>格式>标准/超清（目标是默认）

![](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=ZWU3OTEyMDMyMTVjZGUwYjY5MzRkMjFkZTE4OThlZjJfM2RjMjc4NWFmMzcxNWMyNzU0MGY0OWYwZjEzNjEzNDFfSUQ6NzYzNzQwMzQ2MTU3OTAzNDMzNl8xNzgzNDA2MzAzOjE3ODM0MDk5MDNfVjM)

### 范围说明（In Scope）

- 默认模式下支持超清规格，超清只在特定条件下触发
- 主摄与长焦摄像头（1x-10x变焦范围，暂定）
- 明亮环境触发（环境光满足算法阈值）
- 多帧合成输出 25MP 分辨率

### 明确不做（Out of Scope）

- 前置、超广角摄像头不支持
- 10x 以上变焦不支持（暂定）
- 暗光/夜景环境不触发（环境光低于阈值时回退普通模式或提示用户）
- 视频模式不支持
- 人像模式、专业模式等其他拍摄模式暂不支持

## 3. 方案说明

### 核心策略

1. **触发策略**：明亮环境 + 主摄/长焦 + 1x-10x 变焦范围内自动启用
2. **算法策略**：ArcSoft 25M TurboFusion 多帧合成，平衡解析力与性能
3. **回退策略**：条件不满足时回退至普通默认模式拍摄

### 关键交互或流程

```
        用户进入默认模式 → 点击"设置" → 照片→格式→选择"超清"
                                    ↓
                 
                          ┌─────────┴─────────┐
                             ↓                   ↓
                            环境/摄像头/变焦        条件不满足
                            条件满足                  ↓
                                 ↓              回退12MP
                            触发 TurboFusion         
                                 ↓
                            输出 25MP 照片
```

### 算法/画质策略

- **算法来源**：ArcSoft 25M TurboFusion
- **技术原理**：多帧合成，充分发挥传感器解析力
- **画质特征**：

  - 自然、真实、接近光学质感
  - 避免过度算法感与不自然观感
  - 兼具自然氛围、出色清晰度与丰富细节
- **合成帧数**：待算法团队确

### 硬件或平台依赖

- **适用机型**：26111 系列（4a / 4a Pro）
- **软件平台**：NOS 5.1
- **传感器要求**：主摄/长焦需支持全尺寸 50MP 输出（用于多帧合成降采样/融合）
- **ISP/算力**：需满足多帧合成实时处理需求

## 5. 指标与验收

### 用户体验指标

- 25MP 模式 shot-to-shot 间隔 ≤ 50MP 模式的 70%
- 单张存储占用 ≤ 50MP 模式的 60%
- 高像素面板用户选择率：25MP 成为最常用高像素选项

### 画质指标

- 解析力：MTF50 优于默认 12MP 模式 ≥ 30%
- 噪声控制：SNR 不低于默认模式
- 色彩还原：ΔE ≤ 默认模式基准
- 自然度：无过度锐化/涂抹感（主观评分 ≥ 4.0/5.0）

### 性能指标

- 拍摄耗时：从点击快门到可拍摄下一张 ≤ 2.5s（明亮环境）
- 合成耗时：多帧合成处理 ≤ 1.5s
- 功耗：单张拍摄功耗 ≤ 50MP 模式的 80%

### 稳定性指标

- 崩溃率 ≤ 0.1%
- 合成失败率 ≤ 0.5%（失败时回退普通模式）

### 验收方式

- 客观指标：实验室 MTF/SNR/ΔE 测试
- 主观评估：内部画质评审团盲测（≥ 10 人）
- 性能测试：自动化 shot-to-shot 与功耗测试
- 用户验证：Dogfood 使用数据与反馈收集

## 8. 初步评审

### 开发评审

- **触发条件需精确定义**："明亮环境"和"一定倍率"需要量化为 lux 阈值和变焦范围，否则实现侧无法收敛
- **ArcSoft 新接入风险**：首次集成该算法，需预留充足联调与 tuning 时间，建议 M1-M2 之间预留 2 周 buffer
- **200MP 移除影响**：需确认是否有用户在用 200MP，移除后是否有投诉风险，建议先埋点后移除
- **Pipeline 改动范围**：高像素模式选项调整涉及相机 APP + HAL + 算法层，需评估改动面
- **降级策略待补充**：当 25MP 合成失败时，回退普通模式是否需要用户提示？

### 测试评审

- **场景覆盖**：需覆盖 1x/2x/3x/5x 各变焦档位的主摄/长焦切换边界
- **环境覆盖**：明亮环境边界测试（刚好满足/不满足阈值）
- **兼容性**：需验证 25MP 与 HDR、AI 场景识别等默认模式功能的互斥/共存关系
- **回归范围**：高像素面板改动需回归 50MP 模式、默认模式、变焦流畅性
- **客观信号**：需定义 25MP 合成成功的 EXIF 标记或日志信号，便于自动化验证

### 高风险项

- **🔴 高**：ArcSoft SDK 新接入，交付时间与集成复杂度存在不确定性，可能阻塞版本
- **🔴 高**："明亮环境"阈值定义不清，可能导致 tuning 阶段反复调整触发逻辑
- **🟡 中**：200MP 直接移除可能影响部分用户，建议先降级为隐藏/折叠而非直接删除
- **🟡 中**：25MP 与 50MP 差异化若不够明显，用户可能感知不到价值
