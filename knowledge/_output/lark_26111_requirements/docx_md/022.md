# 需求背景

### 2.1 产品 / 数据现状

- <cite doc-id="VPYHwL7vOiOUYEkS0nulJXJIg3B" file-type="wiki" title="26111/26121 视频能力建设 Overview" type="doc"></cite>
- Nothing 相机视频模式目前缺少面向用户的专业参数控制能力。用户在录制视频时无法常态调节曝光偏移（EV），也无法手动指定白平衡，只能依赖全自动的 3A 算法。
- 自动 AE 算法在持续调整曝光的过程中，可能出现曝光跳变，在逆光、混合光源等场景下尤为明显，被评测者指出是「削弱对整个系统信心」的核心痛点之一。
- 自动白平衡（AWB）在室内混合光源、场景转换等场景下容易出现色温大幅度变化，影响成片一致性。
- 25111 Pro 目前仅支持「小太阳」触摸曝光，且对焦框消失后即失效，不具备持久调节能力。

### 2.2 用户调研

- **调研方式：**竞品体验分析
- **样本情况：**Pixel 9 Pro、三星 S25 Ultra、iPhone 17 Pro、Vivo X300、Vivo V70、OPPO Reno 15 视频专业参数能力对比
- **核心结论：** 独立 EV 调节已是主流竞品视频模式标配，但绝大多数在录制中只提供「小太阳」触摸曝光，并非真正意义上的独立 EV 控件；手动白平衡则是更高层次的差异化能力，仅少数竞品支持。Pixel 9 Pro 提供了一套兼顾专业度与易用性的实现方案，具有较高参考价值。

### 2.3 竞品 / 对标情况

# 需求目标

1. 在视频模式、慢动作模式和前后双录模式的下拉菜单中新增「曝光」和「白平衡」两个独立开关。
2. 「曝光」开关：提供 EV 偏移滑轨，范围 -2EV \~ +2EV，与拍照模式曝光开关对齐，录制前后均可实时调节。
3. 「白平衡」开关：提供白平衡滑轨，显示绝对 K 值，可调范围以当前 AWB 检测值为基准浮动；调节不影响系统色调判断。
4. 参数在退出相机后还原，避免下次开机带着上次参数误导用户。
5. 对齐 Pixel 9 Pro 的专业参数体验，兼顾专业控制权与低上手门槛。

# 需求范围

### 4.1 范围内

- **项目范围：** 26111 首次上项。
- **模式范围：** 视频模式、慢动作模式和前后双录模式
- **生效范围：** 所有视频规格均支持该能力。
- **设置入口：** 视频录制界面下拉菜单，「曝光」和「白平衡」各为独立开关。
- **行为控制范围：**

  - 手动 EV 偏移调节（-2EV \~ +2EV，自动曝光基础上的偏置，不锁定快门 / ISO）
  - 手动白平衡调节（显示绝对 K 值，可调范围以当前 AWB 检测值为基准浮动，不锁定色调）
  - 各开关独立关闭时对应参数归零

### 4.2 范围外

- 拍照、夜景、人像、等其他模式。
- 手动快门速度、手动 ISO 等其他专业参数。
- 色调（Tint）偏移——本期不做，系统自动判断。
- WB 预设档位（晴天 / 阴天等）——本期不做，仅提供滑轨。
- 老项目回落支持。

# 产品流程与交互

### 5.1 交互原则

- 「曝光」和「白平衡」各为独立开关，互不影响，用户可单独开启任意一项。
- 入口形式沿用 Nothing 拍照模式中现有「曝光」开关的交互语言，降低用户学习成本。
- EV 和 为偏移逻辑，自动算法持续运行，用户只是施加一个偏置，上手成本低。
- WB 显示绝对 K 值，让用户有直观的色温认知，用户调节后锁定到当前K值。但可调范围以当前检测值为基准浮动，避免用户设定超出当前场景范围的极端值。
- 参数在退出相机后自动还原，下次进入视频模式时始终从干净状态开始。

### 5.2 流程说明

**曝光调节**

1. 用户进入视频模式、慢动作模式和前后双录模式，下滑打开下拉菜单。
2. 下拉菜单中可见「曝光」开关，默认关闭。
3. 点击开启后，滑轨从屏幕底部弹出（交互形式参考拍照模式曝光开关）；范围 -2EV \~ +2EV，默认值 0。
4. 拖动滑轨，画面曝光实时变化；关闭弹层后偏移值继续生效。
5. 再次点击开关关闭时，EV 归零，画面恢复自动曝光。
6. 退出相机应用后，EV 自动还原，开关恢复关闭状态。

**白平衡调节**

1. 下拉菜单中可见「白平衡」开关，默认关闭。
2. 点击开启后，滑轨从屏幕底部弹出；显示当前绝对 K 值；可调范围以当前 AWB 检测值为基准浮动。
3. 拖动滑轨，画面色温实时变化，K 值实时更新；色调不受影响，系统 AWB 暂停运行。
4. 关闭弹层后，当前 K 值设定继续生效。
5. 再次点击开关关闭时，WB 归零，画面恢复自动白平衡。
6. 退出相机应用后，WB 自动还原，开关恢复关闭状态。

# 需求说明

### 6.1 视频模式下拉菜单新增「曝光」开关

**功能支持范围**

| **维度** | **说明** |
|-|-|
| 模式范围 | 视频模式、慢动作模式和前后双录模式 |
| 摄像头范围 | 覆盖视频模式下可参与录制的所有物理镜头和焦段 |
| 焦段范围 | 覆盖视频模式下可参与录制的所有焦段 |
| 地区范围 | Global |
| 项目差异 | 26111 系列首次支持 |

**功能详细说明**

- 触发入口：视频模式、慢动作模式和前后双录模式下拉菜单 → 「曝光」开关。
- 默认状态：关闭，即默认使用 AE 自动曝光。
- 开启时：底部弹出 EV 滑轨，范围 -2EV \~ +2EV，步长 1/3EV；关闭弹层后偏移继续生效，下拉菜单开关图标显示激活态（与 tuning 逻辑一致）。
- 关闭时：EV 偏移归零，画面恢复自动曝光。
- 录制前和录制中均可拖动滑轨实时调节。

**限制与说明**

- 仅对视频模式、慢动作模式和前后双录模式生效，不影响拍照等其他模式。
- EV 调节为曝光偏移，不等同于锁定曝光，AE 算法持续运行。
- 退出相机应用后自动归零。

### 6.2 视频模式下拉菜单新增「白平衡」开关

**功能支持范围**

| **维度** | **说明** |
|-|-|
| 模式范围 | 视频模式、慢动作模式和前后双录模式 |
| 摄像头范围 | 覆盖视频模式下可参与录制的所有物理镜头 |
| 焦段范围 | 覆盖视频模式下可参与录制的所有焦段 |
| 地区范围 | Global |
| 项目差异 | 26111 系列首次支持 |

**功能详细说明**

- 触发入口：视频模式、慢动作模式和前后双录模式下拉菜单 → 「白平衡」开关。
- 默认状态：关闭，即默认使用 AWB 自动白平衡。
- 开启时：

  - 底部弹出 WB 滑轨，显示当前绝对 K 值；
  - 可调范围以当前 AWB 检测值为基准浮动（具体偏移范围待算法确认）；
  - 拖动时 K 值实时更新，画面色温实时变化；
  - 色调不受影响，系统自动判断，但是锁定在用户手动拉动WB滑轨时；
  - 关闭弹层后当前 K 值设定继续生效，下拉菜单开关图标显示激活态。
- 关闭时：WB 设定归零，画面恢复自动白平衡。
- 录制前和录制中均可拖动滑轨实时调节。

**限制与说明**

- 仅对视频模式、慢动作模式和前后双录模式生效，不影响拍照等其他模式。
- WB 调节为相对 AWB 偏移，不等同于锁定白平衡，色调不受影响，系统 AWB 持续运行。
- 本功能与「锁定白平衡」的优先级关系待确认（见第 11 章）。
- 退出相机应用后自动归零。

# 关键依赖与约束

### 7.1 技术依赖

- **硬件依赖：** 无额外硬件依赖，基于现有 ISP 与 AE / AWB 算法能力实现。
- **平台依赖：** 待确认（Base S6650 / Pro S7635 平台 API 支持情况）。
- **算法依赖：**

  - 需确认 EV 偏移 API 是否支持 -2EV \~ +2EV 范围及步长精度。
  - 需确认 AWB 色温写入接口是否支持「以当前检测值为基准浮动」的相对偏移模式。

- **性能 / 功耗约束：** 预期与当前基线一致，待算法团队确认无额外 overhead。

- **SKU / 项目差异：** 当前明确为 26111 首次上项。

# 指标与验收

### 10.1 成功指标

- 用户在视频模式下可通过下拉菜单独立开启曝光和白平衡调节。
- EV 调节实时生效，录制中调整的 EV 偏移与成片曝光一致。
- WB 调节实时生效，成片色温与设定 K 值方向一致，色调不受影响。
- 关闭开关后，对应参数正确归零，不影响默认录制体验。
- 退出相机后重新进入，两个开关均恢复关闭状态，参数还原为默认值。

### 10.2 验收标准

| **#** | **验收项** | **预期结果** | **优先级** |
