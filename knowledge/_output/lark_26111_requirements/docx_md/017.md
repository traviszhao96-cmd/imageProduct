## 背景与目标

### 2.1 用户问题

- 拍照模式下主摄与长焦均已支持 ISZ，视频模式没有，用户在视频中变焦至同等倍率只能使用数码变焦，画质明显劣化。
- 变焦指示器在视频模式下缺少对应点位，用户无法感知/直达更优画质的倍率。

### 2.2 行业现状

- 主流竞品在视频模式下普遍支持基于 sensor 裁切的无损变焦点位，并在变焦条上显式标出，属于中高端机型的基础能力。
- 通用背景见<cite doc-id="VPYHwL7vOiOUYEkS0nulJXJIg3B" file-type="wiki" title="26111/26121 视频能力建设 Overview" type="doc"></cite>。

### 2.3 用户目标

- 视频变焦到常用倍率（2x / 4x / 8x）时获得明显优于数码变焦的画质。
- 变焦交互与拍照模式一致，无新增学习成本。

### 2.4 产品目标

- 视频类模式补齐 ISZ 能力，拉齐拍照与视频的变焦画质，消除能力断档。

## 功能定义

### 3.1 功能名称

视频 ISZ（In-Sensor Zoom）

### 3.2 一句话描述

在视频类模式下支持主摄 / 长焦的 sensor 内裁切变焦，并在变焦指示器上增加对应点位。

### 3.3 范围

**范围内**

- 项目范围：26111 / 26121 首次上项。
- 模式范围：视频模式、慢动作及其它支持变焦的视频类模式。
- 规格范围：上述模式下的**所有视频规格**（1080P30/60、4K30、SAT 等）。
- 摄像头范围：跟随各模式原有镜头支持情况——原本支持主摄的支持主摄 ISZ，原本支持长焦的支持长焦 ISZ。

**范围外**

- 拍照模式 ISZ（已有能力）。
- 超广角 ISZ。
- 前后双录（其 ISZ 扩展归入双录升级 PRD）。
- 最高 ISZ 点位以上的画质增强（仍为数码变焦）。
- 老项目回落。

## 设计稿

- 无需，从用户端仅有变焦指示器的变化。

## 需求

### R1 · 焦段与变焦指示器定义

**镜头规格与 ISZ 点位**

| **机型** | **镜头** | **Sensor** | **显示焦距 / 倍率** | **ISZ 点位** |
|-|-|-|-|-|
| 26111  | 主摄 | 200M HP5 | 23mm / 1x | 2x（46mm）、4x（92mm） |
| 26121 | 主摄 | 50M IMX896 | 24mm / 1x | 2x（48mm） |
| 26121 | 长焦 | 50M JN5 | 80mm / 3.5x | 7x（160mm） |

**变焦指示器点位**

| **机型** | **视频类模式变焦指示器点位** |
|-|-|
| 26111 | 0.6x – 1x – 2x – 4x |
| 26121 | 0.6x – 1x – 2x – 3.5x – 7x |

- 新增点位的交互形式（吸附、点按直达）与原视频模式保持一致。
- 变焦最大范围维持现有定义不变。

### R2 · 视频模式 ISZ

- 用户变焦至 ISZ 点位时，由对应 sensor 内裁切出图，画质优于数码变焦。
- ISZ 实现为独立虚拟摄像头（逻辑 camera），变焦经过点位时无缝切入/切出，无可感知跳变或卡顿。（实现方式待工程确认）
- 录制前与录制中均可进入/退出 ISZ。
- 除变焦指示器新增点位外，无其他新增 UI 与用户提示。
- **26121 的 3.5x 点位归属**：3.5x 默认由长焦镜头出图（SAT 逻辑）；当长焦不可用（如对焦距离过近、暗光策略）时，回落为主摄 2x ISZ 数码变焦。

### R3 · 慢动作模式 ISZ

- 现状：慢动作仅支持主摄，变焦条显示 2x 但实际为数码放大。
- 本期：2x、4x 点位实打实切换为主摄 ISZ。
- 其余交互不变。

### R4 · 与 EIS / 效果链路的关系

- 当前理解：EIS 处理在 ISZ 裁切之后叠加。**待工程确认。**
- EIS 开关关闭时，ISZ 行为不变，仅去除 EIS 裁切。
- 滤镜 / Tuning 在 ISZ 下正常生效，效果一致性待验证。

## 关键依赖与约束

| **硬件依赖** | **200M sensor 视频链路下 2x / 4x 裁切出图能力；长焦 sensor 裁切出图能力** |
|-|-|
| 平台依赖 | 虚拟摄像头在视频 / 慢动作链路下的支持情况，待确认 |
| 算法依赖 | ISZ 与 EIS、滤镜、Tuning 的叠加顺序与效果一致性，待确认 |
| 性能 / 功耗 | 4K + ISZ + EIS 同时开启下的性能余量与发热，待评估；慢动作高帧率下 ISZ 出图能力待评估 |

## 指标与验收

### 8.1 成功指标

- 视频类模式下各 ISZ 点位画质显著优于现有同倍率数码变焦。
- 变焦经过 ISZ 点位时切换平滑，无可感知跳变。
- 变焦指示器点位显示正确，交互与拍照模式一致。

### 8.2 验收标准

| **#** | **验收项** | **预期结果** |
|-|-|-|
| 1 | 视频模式 2x 录制 | 主摄 ISZ 生效，清晰度优于数码变焦 |
| 2 | 26111 视频模式 4x 录制 | 主摄 4x ISZ 生效 |
| 4 | 26121 视频模式 7x 录制 | 长焦 ISZ 生效 |
| 5 | 慢动作 2x | 主摄 ISZ 生效（非数码放大） |
| 6 | 录制中跨越 ISZ 点位 | 切换无跳变、无卡顿、无中断 |
| 7 | 所有视频规格（含 4K、SAT） | ISZ 均生效 |
| 8 | EIS 开/关 | ISZ 行为一致 |
