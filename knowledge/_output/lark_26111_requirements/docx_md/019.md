# **2. 需求背景**

## **2.1 产品 / 数据现状**

- <cite doc-id="VPYHwL7vOiOUYEkS0nulJXJIg3B" file-type="wiki" title="26111/26121 视频能力建设 Overview" type="doc"></cite>
- Nothing 相机视频模式目前默认开启 EIS（电子防抖），但缺少面向用户的显式开关。用户无法主动关闭 EIS，也无法感知当前 EIS 是否生效。
- EIS 在提升手持稳定性的同时，会对画面进行裁切，导致视角（FOV）缩小，并可能出现画面的偏移。**对于使用三脚架固定机位拍摄、或追求最大画角的创作者而言，强制开启的 EIS 反而会带来负面体验。**



## **2.2 用户调研**

- 调研方式：竞品体验分析
- 样本情况：Google、三星视频防抖开关对比
- 核心结论：部分竞品均将EIS视频防抖作为可见开关暴露给用户，用户可在「相机设置 → 视频」区域便捷切换；用户理解成本较低。

## **2.3 竞品 / 对标情况**

- 对标结论：Nothing 可参考主流竞品方案，在相机设置的视频区域新增「视频防抖」开关，默认开启，允许用户按需关闭。

# **3. 需求目标**

1. 在相机设置中新增「视频防抖」功能开关，允许用户选择在视频模式和前后双录模式录制时是否启用防抖。
2. 默认开启 EIS，保持当前用户体验；用户可主动关闭以获取最大画角。
3. 对齐竞品的用户感知逻辑，降低用户理解成本。

---

# **4. 需求范围**

## **4.1 范围内**

- 项目范围：26111 首次上项。
- 模式范围：视频模式、前后双录模式。
- 生效范围：上述模式下的所有摄像头的所有支持EIS防抖的视频规格均支持该能力。
- 设置入口：相机设置页中的视频设置区域。
- 行为控制范围：控制录制过程中是否启用电子防抖（EIS）。

## **4.2 范围外**

- 视频模式、慢动作模式外的拍照、夜景、人像等其他模式。
- 光学防抖（OIS）策略，不受本开关影响。
- 与本功能无关的稳定化算法参数调整。

---

# **5. 产品流程与交互**

## **5.1 交互原则**

- 用户需明确知道该开关控制的是「录制过程中是否启用电子防抖」，而非录制前的预览防抖状态。
- 默认行为保持当前 EIS 开启逻辑，避免影响已有用户习惯。
- 开关状态实时生效，用户在录制前可随时切换。
- 保证功能的兼容性，对视频模式与前后双录模式下对所有视频规格生效。

## **5.2 流程说明**

1. 用户进入相机设置页，滑动到视频相关设置区域。
2. 用户可看到「电子防抖（EIS）」开关，默认开启。
3. 当开关开启时，录制过程中 EIS 正常运作，提供稳定画面，画角相应缩小。
4. 当开关关闭时，录制过程中 EIS 不运作，画角恢复最大，画面稳定性依赖拍摄者持机稳定性或外部稳定设备。

# **6. 需求说明**

## **6.1 视频模式 / 慢动作模式新增「电子防抖（EIS）」设置项**

**功能支持范围**

| **维度** | **说明** |
|-|-|
| 模式范围 | 视频模式、前后双录模式 |
| 摄像头范围 | 覆盖上述模式下可参与录制的所有物理镜头 |
| 焦段范围 | 覆盖上述模式下可参与录制的所有焦段 |
| 地区范围 | Global，不区分地区 |
| 项目差异 | 26111 系列首次支持 |

**功能详细说明**

- 触发入口：相机 → 设置 → 视频区域 → 视频防抖。
- 默认状态：开启，即默认使用 EIS 进行防抖，保持现有体验。
- 当开关开启时，录制过程中 EIS 正常运作；画面经过防抖裁切，视角相应缩小。
- 当开关关闭时，录制过程中 EIS 不运作；画面保持最大视角，稳定性由拍摄者自行保障。
- 开关状态切换后无需额外用户提示。

**限制与说明**

- 仅对视频模式、前后双录模式生效，不影响拍照等其他模式。
- OIS（光学防抖）不受本开关影响，由硬件独立控制。
- 上述模式下所有视频规格均支持该能力。

# **10. 指标与验收**

## **10.1 成功指标**

- 用户在视频模式与慢动作模式下可自主选择是否启用电子防抖（EIS）。
- 开启 EIS 时，录像过程中防抖生效，画面稳定性符合预期。
- 关闭 EIS 时，录像过程中防抖不生效，画角恢复至最大 FOV。
- 默认开启状态下，现有 EIS 体验与行为保持不变。

## **10.2 验收标准**

- 视频设置页存在「视频防抖」开关，默认开启。
- 开关开启时，录像过程中 EIS 正常运作，画角因裁切相应缩小。
- 开关关闭时，录像过程中 EIS 不运作，画角恢复最大。
- 本功能在视频模式与前后双录模式生效，其他模式不受影响。
- OIS 行为不受本开关影响。
