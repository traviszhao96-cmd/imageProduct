# 功能设计

按功能点写，每个功能点把范围、交互、逻辑、限制放在一起。

## ~~【评估项】4K 分辨率支持~~

#### 功能支持范围

- **机型范围**：当前评估面向 Pro 机型；Base机型和25131 不适用，不展示该选项。
- **分辨率选项**：1080P（默认）/ 4K（评估落地后新增）
- **帧率**：30fps（与 1080P 一致，4K 下同样锁定 30fps）
- **比例**：16:9

#### 功能详细说明

- 4K 选项仅在平台能力评估通过且开发验证完成后上线；不适用机型不显示该选项，不做降级提示或灰化处理。
- **分辨率选择入口**：与普通视频模式规则对齐（顶部工具栏或设置项），录制开始前可选，录制开始后不可更改。
- 选择 4K 后，系统记忆上次选择，下次进入双录模式时保持上次分辨率；1080P 为出厂默认。
- 4K 模式下功耗与存储占用均高于 1080P，需在验收前确认平台热功耗上限并写入验收口径（见 7.2）。
- 若平台评估不通过，该功能整体不落地，不影响其他几项 v2 能力的交付节奏。

#### 限制与说明

- 当前为评估项，技术结论未出前不进入开发排期，不计入 v2 基础交付范围。
- 4K 双录对 ISP、录制链路、存储写入带宽的要求需与平台/算法团队专项确认。
- 若评估结论为不支持，本节整体移除，不影响 v2 其他功能。



## 录制前后置镜头选择

#### 功能支持范围

- **模式范围**：视频前后双录模式，录制开始前
- **机型差异**： 

  - 26111 Base：超广 / 主摄，二选一
  - 26111 Pro：超广 / 主摄 / 长焦（3.9x），三选一
- **焦段范围**：

| **机型** | **档位** | **焦段** |
|-|-|-|
| Base / Pro | 超广 | 0.6x - 2x |
| Base / Pro | 主摄 | 1x - 7x |
| 仅 Pro | 长焦 | 3.9x - 20x |

- **地区范围**：全部

#### 功能详细说明

v1（25131）前后双录模式下，后置镜头不可选择，默认锁定主摄——即便机型配备超广，双录模式中也无法切换。v2 在 26111 上引入录制前镜头选择能力。

**选择交互**

- 用户进入双录模式后，预览页面底部变焦条显示可选镜头档位，点击即切换。
- Base 显示三个档位按钮（超广0.6x、主摄1x、2x）；Pro 显示三个档位按钮（超广0.6x、主摄1x、长焦3.9x）。
- 切换镜头时提供模糊转场动画，规格与 v1 其他镜头切换动画一致。
- 录制开始后，后置焦段锁定，不可再切换。

**各档位变焦行为**

- 选择超广：变焦范围 0.6x - 2x
- 选择主摄：变焦范围 1x - 7x
- 选择长焦（仅 Pro）：变焦范围 3.9x - 20x

**默认值**

- 默认选择主摄，进入双录模式时不重置用户上次选择。

#### 限制与说明

- 录制中不支持切换后置镜头。
- 长焦档位仅在 26111 Pro/Ultra 上显示，Base 变焦条不出现长焦按钮，无需做灰化或降级提示。

## 录制中前后摄主副位置互换

#### 功能支持范围

- **模式范围**：视频前后双录模式，录制进行中
- **布局范围**：画中画（PiP）与上下均分（Split Screen）均支持
- **地区范围**：全部

#### 功能详细说明

**触发方式**

- 使用与普通视频模式相同的前后摄切换按钮触发，操作路径与用户已有习惯一致。
- 录制中可随时触发，无需停止录制，触发后立即生效。

**画中画模式下的互换行为**

- 互换后，原小窗画面升级为全屏主画面，原主画面缩至小窗。
- 小窗位置：互换后小窗保留互换前的屏幕位置，不重置至默认右上角。
- 小窗大小：互换后沿用互换前用户选择的大小档位（与 5.4 小窗档位联动）。

**上下均分模式下的互换行为**

- 互换后上下画面位置对调（前置与后置画面位置整体交换）。

**曝光状态处理**

- 曝光值跟随摄像头迁移，不跟随窗口位置迁移。 

  - 示例：互换前用户对后摄手动调整了 EV +1，互换后后摄变为小窗，EV +1 保留不重置；前摄切换为主画面后，曝光状态亦保持互换前的值。
- 互换后，用户仍可在当前布局下继续分别调整曝光。

  - 画中画模式：可以调节当前主窗口曝光，不可调节小窗曝光
  - 均分模式：上下两边曝光可以分别调整

**录制文件**

- 互换操作不中断录制文件写入。
- 互换次数通过埋点记录（见第 9 章）。

#### 限制与说明

- 录制中互换不影响音频录制策略（与 v1 音频策略一致）。
- 录制中主副互换的信号源切换逻辑需与开发团队确认是否支持无缝实现；若存在限制，见 10.2 兜底方案。

## 小窗大小两档切换（画中画模式）

#### 功能支持范围

- **模式范围**：画中画（Picture-in-Picture）布局
- **操作时机**：录制前与录制中均可操作
- **地区范围**：全部

#### 功能详细说明

**两档尺寸定义**

| **档位** | **尺寸（px）** | **宽高比** | **圆角** | **阴影** |
|-|-|-|-|-|
| Small（默认） | 360 × 480 | 3:4 | 13dp | elevation 4-8dp |
| Large（新增） | 待确认 540 × 720 | 3:4 | 13dp | elevation 4-8dp |

- 两档均保持 3:4 宽高比与 13dp 圆角，视觉规格与 v1 小窗一致，仅尺寸变化。
- Large 档具体数值以设计稿为准；需确保大档小窗不遮挡底部录制控制栏的核心操作区域（拍照、暂停按钮等）。

**切换方式**

- 切换入口：画中画模式下，轻触小窗右上角的大小切换图标，在 Small 与 Large 之间单次切换。
- 切换时机：录制前和录制中均可操作，不中断录制。
- 动画：切换时小窗以当前中心点为基准执行缩放动画，时长约 200ms，使用标准缓动曲线（具体参数以设计稿为准）。
- Toast：切换时通过 toast 提示当前档位：「Small Window」或「Large Window」。

**位置行为**

- 切换大小后，小窗以当前中心点为基准缩放，位置不重置。
- 若切换后小窗超出屏幕边界，自动收紧至边界内最近合法位置（与 v1 边界约束逻辑一致）。
- 切换大小后，用户仍可继续拖动小窗至任意合法位置。

**与录制中主副互换的联动**（见 5.3）

- 录制中触发主副互换时，小窗档位随摄像头迁移保留，不重置为 Small。

**默认值与记忆策略**

- 默认档位：Small（延续 v1 行为，不破坏已有用户习惯）。
- 不跨会话记忆档位，每次进入双录模式重置为 Small。

#### 限制与说明

- 仅在画中画模式下生效；上下均分模式不涉及小窗大小。
- 不支持手势连续缩放（无 pinch-to-zoom），仅两档固定切换。
- Large 档具体尺寸数值以设计稿为准，本文当前为估算值，不作为开发依据。

## 双文件独立保存

#### 功能支持范围

- **模式范围**：视频前后双录模式
- **机型范围**：26111 Base 与 26111 Pro/Ultra 均支持
- **操作时机**：录制前选择，录制开始后不可更改
- **地区范围**：全部

#### 功能详细说明

**保存模式选项**

双录模式下提供两种保存方式，用户可按需选择：

| **模式** | **说明** | **输出文件数** |
|-|-|-|
| 合并保存（默认） | 前后摄画面合成为单文件，延续 v1 行为 | 1 个 |
| 分开保存（新增） | 前后摄画面各自独立输出为单独文件 | 2 个 |

**选择入口**

- 入口位于双录模式顶部工具栏的下拉二级菜单中，标签为「保存方式」（英文：Save As）。
- 默认为「合并保存」，与 v1 行为保持一致，不破坏已有用户习惯。
- 选择在录制前生效，录制开始后不可变更；录制结束后保留上次选择。

**分开保存的文件命名规则**

选择分开保存时，录制结束后生成两个文件，命名规则如下：

```Plain Text
VID_YYYYMMDD_HHMMSSMMM_DUAL_REAR.mp4    // 后置摄像头画面
VID_YYYYMMDD_HHMMSSMMM_DUAL_FRONT.mp4   // 前置摄像头画面
```

- 两个文件时间戳一致，以录制开始时刻为准。
- REAR / FRONT 后缀按**物理摄像头来源**命名，与录制过程中主副位置无关。即 REAR 文件始终为后置摄像头的完整录制内容，FRONT 文件始终为前置摄像头的完整录制内容，不受录制中主副互换操作的影响。

**相册展示**

- 两个文件在相册中作为独立条目分别展示，不做关联分组。
- 每个文件的详情页均显示 DUAL Tag（与合并保存一致），帮助用户识别素材来源。
- 相册详情页文件名显示完整命名（含 DUAL_REAR / DUAL_FRONT 后缀）。

**合并保存模式不受影响**

- 选择合并保存时，行为与 v1 完全一致：单文件输出，命名规则为 `VID_YYYYMMDD_HHMMSSMMM_DUAL.mp4`，相册显示 DUAL Tag。

#### 限制与说明

- 录制中不可切换保存方式。
- 两个独立文件不支持在相册中作为组合素材联动播放（本期范围外）。

# 效果定义与验收标准

## 预期效果

- 26111 Base 用户在录制前可选超广或主摄，Pro/Ultra 用户额外可选 3.9x 长焦，满足演出、体育赛事等场景的远景构图需求。
- 用户在双录录制过程中可随时互换主副摄，操作流畅无卡顿，录制文件连续无中断。
- 画中画模式下小窗大小可在录制前后灵活切换，大档模式下双画面内容均清晰可辨且不遮挡操作区。
- 4K 双录（如评估通过并落地）在 26111 Pro/Ultra 上稳定运行，无过热停录或明显掉帧。

## 验收口径

**录制中主副互换**

- 互换操作响应时间：待填（参考普通模式前后摄切换基准值）
- 互换后录制文件连续，无黑帧、中断或音画不同步
- 曝光值在互换后正确跟随摄像头保留，不发生异常重置
- 互换动画（模糊转场）完整呈现，无闪烁或帧跳变
- 录制中互换操作可重复执行，不存在累积性能劣化

**镜头选择**

- Base 变焦条显示超广 / 主摄两个档位，Pro/Ultra 显示超广 / 主摄 / 长焦三个档位，Base 不出现长焦按钮
- 选择长焦后录制，后置画面来源正确，锁定在 3.9x，无连续变焦
- 镜头切换动画规格与 v1 一致
- 录制开始后档位锁定，切换按钮不可操作

**小窗大小切换**

- Small ↔ Large 切换动画流畅，时长约 200ms，无卡顿或帧率下降
- Large 档小窗不遮挡底部拍照、暂停等核心操作区
- 切换后小窗位置以中心点为基准缩放，超界时自动收紧至边界
- Toast 文案正确展示（「Small Window」/「Large Window」）
- 录制中切换与录制前切换行为一致，不中断录制

**4K 双录（如落地）**

- 4K 30fps 双录在标准测试场景下连续录制 [待定] 分钟，无掉帧或过热停录
- 输出文件分辨率为 3840×2160，帧率符合预期，文件完整
- 热功耗不超过平台限制阈值（阈值数值待平台评估确认）
- 对比机：待确认（建议覆盖 iPhone、Samsung、vivo X300 同级对标机）
- 对比版本：待确认
- 场景范围：复用前后置视频场景库，并补充长焦双录专项场景
