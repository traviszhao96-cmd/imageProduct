# 2. 需求背景

## 2.1 产品 / 数据现状

- <cite doc-id="VPYHwL7vOiOUYEkS0nulJXJIg3B" file-type="wiki" title="26111/26121 视频能力建设 Overview" type="doc"></cite>
- Nothing 相机视频模式目前仅支持自动白平衡（AWB），录制全程由算法动态调整白平衡数值，用户无法干预。
- 此机制在混合光源环境、长时间固定机位录制的场景会产生明显的问题，可能因为环境光的变化导致白平衡漂移，影响素材的色彩一致性。对于有创作需求的用户他们希望对自己的录制可以有基础的控制。特别是对后期有需求的用户来说，录制中白平衡不稳定可能会增加后期修正的工作量，甚至导致部分镜头无法修复。需要给用户提供主动选择权，在有需要的场景自行锁定白平衡。
- OPPO、iPhone 等主流竞品均已提供「录制过程中锁定白平衡」能力，**Nothing 当前缺失该功能**，在专业用户与内容创作者群体中存在明显的竞争劣势。

## 2.2 用户调研

- 调研方式：竞品体验分析
- 样本情况：OPPO、iPhone 视频模式相关能力对比
- 核心结论：主流竞品均提供“录制过程中锁定白平衡”的能力，交互逻辑相似，用户理解成本较低。

## 2.3 竞品 / 对标情况

- 对标结论：Nothing 可参考主流竞品方案，在视频模式下提供明确的「锁定白平衡」开关，降低用户理解门槛。

# 3. 需求目标

1. 在视频模式中新增「锁定白平衡」功能开关，允许用户选择录制时是否允许白平衡自动变化。
2. 对齐 OPPO、iPhone 等主流竞品的用户感知逻辑，降低用户理解成本。

# 5. 产品流程与交互

## 5.1 交互原则

- 用户需要明确知道该开关控制的是“录制过程中是否锁定白平衡”，而不是录制前的白平衡控制能力。
- 默认行为保持现有 AWB 逻辑，避免影响已有用户习惯。
- 开关开启后，白平衡将在用户点击录制按钮的那一刻锁定。
- 保证功能的兼容性，对所有视频功能生效

## 5.2 流程说明

1. 用户进入相机设置页，滑动到视频相关设置区域。
2. 用户可看到「锁定白平衡」开关，默认关闭。
3. 当开关关闭时，录像过程中自动白平衡正常运作。
4. 当开关开启时，录制开始前自动白平衡仍正常运作。
5. 开始录制后，系统锁定录制起始时的白平衡数据，后续录制中不再改变白平衡数据

# 6. 需求说明

## 6.1 视频模式新增「锁定白平衡」设置项

### 功能支持范围

- 模式范围：视频模式
- 摄像头范围：覆盖视频模式下可参与录制的所有物理镜头
- 焦段范围：覆盖视频模式下可参与录制的所有焦段
- 地区范围：Global，不区分地区
- 项目差异：26111 系列首次支持

### 功能详细说明

- 触发入口：相机 → 设置 → 视频区域 → 锁定白平衡。
- 默认状态：关闭，即默认保持现有的AWB。
- 当开关关闭时，录像过程中自动白平衡正常运作。
- 当开关开启时，录制开始前自动白平衡仍正常运作。
- 当开关开启时，开始录制后，系统锁定录制起始时的白平衡数据，后续录制中不再改变白平衡数据
- 锁定白平衡开启后，不需要额外增加用户提示。

### 限制与说明

- 仅对视频模式生效。
- 不影响录制开始前的 AWB。
- 所有视频规格均支持该能力。

# 10. 指标与验收

## 10.1 成功指标

- 用户在视频模式下可以自主选择录像过程中是否允许锁定白平衡。
- 开启「锁定白平衡」后，录像过程中不再发生白平衡变化。
- 默认关闭状态下，现有自动白平衡行为与体验保持不变。

## 10.2 验收标准

- 视频设置页存在「锁定白平衡」开关，默认关闭。
- 开关关闭时，录像过程中触发原有自动白平衡策略。
- 开关开启时，录制开始后白平衡固定，不受环境影响而变化。
- 本功能仅在视频模式生效，其他模式不受影响。
