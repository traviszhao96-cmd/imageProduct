# SAT 体验优化

<callout emoji="📌">
**结论**
- 跟手性上，主要问题在于点切时动画响应的时间较慢（特别在视频模式录制下），滑动变焦时变焦条不够跟手、画面变化存在较大延迟
- 平滑性上，或可优化动画变化曲线，提升点切时的流畅性
- 画面跳变上，画面视角、色彩均存在较为明显的跳变（OPPO、vivo同样有较为明显的跳变，跳变控制较好的是Samsung，reno16有一定优化）
**可优化维度**
1. 平滑性：优化点切变焦曲线（可参考 Reno16）
2. Fallback 响应速度
3. 跟手性：点切时动画响应速度（特别 video）zoomratio 下发
4. 画面色彩、视角跳变：多摄一致性问题，长期跟进
</callout>



### 点切

- 跟手性上，关注点击变焦到画面动画开始变化的间隔时间（T1），base/pro动画响应速度较慢（特别在视频模式录制下）

  - 照片模式下：reno15 > v70 > pro > s25ultra > base
  - 视频模式下（录制）：reno15 > v70/s25ultra > pro > base
- 平滑性上，关注变焦动画的帧率、变化曲线

  - 变焦动画帧率（有效动画帧数/T2-T1）上无明显差距
  - 变化曲线上，base/pro/v70 变化速率曲线较平缓，reno15/s25ultra 曲线变化较大，其中 reno15 是从慢到较快再到慢，s25ultra 是从极快到慢。主观感受上，reno15/s25ultra 变焦体验更为丝滑，或可优化变化曲线提升 SAT 体验
- 画面跳变上，关注切换镜头时画面视角、色彩是否出现明显跳变，以及跳变发生的时间节点（如果跳变在动画进行或刚结束的过程中发生，对用户感知会比较小，但如果动画结束画面稳定后再次发生跳变，会较容易被感知）

  - base 画面视角跳变比较明显，reno15/v70 色彩跳变比较明显
  - 跳变发生在动画结束后时间（T3-T2）：base/pro/reno15/v70 都差不多，s25ultra会出现动画停止过后的跳变，但其画面跳变较小，不太明显

### 滑动变焦

- 跟手性上，关注变焦条/变焦环是否跟手，画面变化是否跟上变焦操作变化

  - 跟手性主观评价：reno16 > s25ultra > pro/base
  - base/pro 变焦问题：单手拍摄时直接拉变焦条，拉一下变焦常常只能到二倍三倍区间，v70和17pro是变焦盘的形式，变焦效率好一些，而s25ultra同样是变焦条的形式，拉动变焦效率也比我们更高一些（印度调研同样有用户反馈变焦效率差，要滑很多次的问题）；同样这个问题，不只是大范围变焦，有时变焦后做精细化调整，也需要松开手后再次调整
- 平滑性上，关注滑动变焦过程中画面是否出现顿挫

  - 除 S25ultra 出现较明显的顿挫感外，其他手机平滑性无明显差距
- 画面跳变，关注切换镜头时是否有出现明显的视角、色彩跳变

  - 画面跳变主观评价：S25ultra > reno16 > pro/base/s60

以下为各手机滑动变焦主观评价：

1. base/pro  
跟手性上，变焦条效率差，大范围变焦受限，细节调整时也有手指滑动的阻塞感，同时画面存在较大延迟  
平滑性上，高倍变焦存在一定顿挫感  
画面跳变上，视角、色彩都发生较明显的跳变
2. Samsung（s25ultra）  
跟手性上，变焦条比较跟手，画面上存在较大延迟  
平滑性上，阶梯顿挫感较为明显  
画面跳变上比较好，只有视角小幅跳变，色彩上没有大的跳变
3. OPPO（X8pro）  
跟手性上不错，变焦环和画面都比较跟手  
平滑性上不错  
画面跳变上，视角、色彩都发生较明显的跳变
4. OPPO（reno16）  
跟手性上，变焦环跟手，画面比 X8pro 稍有延迟  
平滑性上不错  
画面跳变上比 X8pro 有所优化，主要集中在广角的视角跳变
5. 小米（Xiaomi15）  
跟手性上，变焦环比其他变焦环的行程长，在大范围反复变焦时手指容易错位，导致无法直接回到1x，画面比较跟手（但偶尔动画会出现卡顿）  
平滑性上不错  
画面跳变上，视角变化尚可，跳变集中在色彩上
6. Apple（iPhone17pro）  
跟手性上很好，变焦环和画面都很跟手  
平滑性上不错  
画面跳变上，主要集中在广角端的视角跳变，其他跳变较小
7. vivo（v50）  
跟手性上，变焦条跟手尚可，画面上存在较大延迟  
平滑性上尚可  
画面跳变上，存在较为明显的视角跳变





### Fallback（长焦近距离切主摄）

- base：切 fallback 稍慢，切换跳变中等，fallback 切回中等（比 pro 稍慢一点）
- pro：切 fallback 中等，切换跳变中等，fallback 切回较快
- OPPO X8pro：切 fallback 较快，切换跳变中等（与 pro 差不多），fallback 切回较快（与 pro 差不多）
- S25ultra：切 fallback 稍慢（与 base 差不多），切换的过程跳变较小，fallback 切回比较迟钝
