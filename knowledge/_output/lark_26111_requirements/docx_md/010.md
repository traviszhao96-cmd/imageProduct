# Camera Style / 风格 PRD

## 1. 文档信息

- 产品模块：Camera / 相机
- 功能名称：Style / 风格
- 文档状态：需求与交互方案稿
- 创建日期：2026/5/28
- 更新日期：2026/7/16

## 2. 本次更新摘要

本轮补齐风格功能的产品定义和交互，主要变化如下：

- 风格是工具栏中的统一入口，包含滤镜和调色两类能力。
- 滤镜改为预览框内的横向画廊切换，使用圆点显示当前位置。
- 调色包含调色盘模式和参数模式；调色盘模式默认展示，参数模式保留 7 项精调。
- 滤镜与调色在 FL 中只作为一条“风格”功能验收，具体子能力和规格限制写入同一行。

## 3. 背景与决策

### 3.1 原功能问题

现有 调色 功能以多个独立参数 滑杆 为主要交互。用户需要先理解 Contrast、Saturation、Warmth、色调、锐化、Grain、Vignette 等参数分别代表什么，再判断应该调整哪个参数、调整方向以及调整幅度。

这种交互对熟悉影像后期的高级用户有效，但对大部分普通相机用户存在明显门槛：

- 参数名称专业，用户难以提前理解调整后的实际效果
- 单个参数只能描述局部变化，用户很难通过多个 滑杆 快速建立完整风格
- 用户需要在参数之间反复切换并观察预览，试错路径较长
- 多项参数组合后容易产生过度调节，用户难以恢复到协调状态
- 功能虽然提供了较强能力，但复杂度会降低用户发现、尝试和持续使用的意愿

因此，本需求并不是简单替换 滑杆 的视觉形式，而是希望重新设计普通用户进入调色功能后的第一层交互。

### 3.2 用户心智

普通用户使用相机调色时，通常先表达的是整体感受，例如：

```Plain Text
更暖一些、更冷一些、更浓郁一些、更柔和一些、更复古一些
```

用户往往不是从“我要将 Warmth 调到 +25、Contrast 调到 +18”开始思考。调色盘 将多个底层参数组合成连续的视觉空间，用户可以直接通过位置和实时预览探索效果，更贴近普通用户对照片风格的理解方式。

参数滑杆 仍然有价值，但更适合作为第二层高级能力，而不是所有用户进入功能后的默认起点。

### 3.3 行业方案判断

从当前主流手机相机和影像产品的发展趋势看，越来越多产品使用调色盘、二维风格空间、摄影风格或类似的组合控制方式，帮助用户快速改变照片整体观感。

这些已落地方案验证了以下方向：

- 用户更容易通过连续视觉空间理解不同风格方向
- 组合调节比逐项理解专业参数更适合作为相机拍摄态入口
- 简单入口与高级参数可以分层共存，而不需要同时暴露
- 实时预览是用户判断调色效果的主要反馈，不需要先理解参数原理

因此，调色盘 不是为了移除专业参数能力，而是作为已经被更多厂商和产品验证过的低门槛交互方案，承担 调色 的默认入口。

### 3.4 方案决策

调色盘 适合用户快速获得整体风格，参数滑杆 适合高级用户精确调整。若两类控件同时修改相同参数，会产生跳变、偏移量、反向同步和解释成本。

在统一 Style / 风格功能下，调色 子能力采用明确的双模式结构：

```Plain Text
调色盘模式：用 调色盘和强度 快速建立整体风格
参数模式：用 7 个独立参数进行完整精调

```

该方案的核心取舍：

- Style 在 FL 中作为一个功能验收；滤镜 与 调色 是子能力，不分别生成独立功能行。调色 的两种模式不同时编辑，以降低控制关系复杂度
- 强度 只控制调色盘体系的贡献，不等于任何单一底层参数
- 色调 和 锐化 不强行加入 调色盘 映射，避免色盘边缘产生不自然效果
- 模式切换后允许用户继续基于当前模式产生新的预览变化

## 4. 目标

- 建立统一的 Style / 风格入口，让用户在同一功能下完成滤镜选择和调色；同时降低 调色 使用门槛，让用户通过调色盘快速获得整体风格
- 用 强度 为调色盘效果提供统一、可理解的强弱控制
- 保留完整参数精调能力，满足高级用户需求
- 避免 调色盘 与 参数滑杆 同时编辑造成跳变和同步复杂度
- 为未来扩展更多参数保留清晰边界
- 以 7 个最终 调色 参数作为效果保存和兼容基础

## 6. 需求范围

### 6.1 功能范围

- 相机拍摄态工具栏中的统一 Style / 风格入口，入口下包含 滤镜 / 滤镜与 调色 / 调色
- 调色盘模式 和 参数模式
- 显式模式切换按钮
- 调色盘和调色盘强度
- 7 个参数的独立 滑杆
- 实时预览、重置、收起和默认保存逻辑
- 预设 保存和老项目兼容建议
- 埋点、验收标准和测试建议

## 7. 参数范围与归属

最终效果包含 7 个 调色 参数：

| 序号 | 参数 | 范围 | 受调色盘影响 | 参数模式可调 |
|-|-|-|-|-|
| 1 | 对比度（Contrast） | -100 到 +100 | 是 | 是 |
| 2 | 饱和度（Saturation） | -100 到 +100 | 是 | 是 |
| 3 | 色温（Warmth） | -100 到 +100 | 是 | 是 |
| 4 | 色调（Tint） | -100 到 +100 | 否 | 是 |
| 5 | 锐化（Sharpen） | 0 到 100 | 否 | 是 |
| 6 | 颗粒（Grain） | 0 到 100 | 否 | 是 |
| 7 | 暗角（Vignette） | 0 到 100 | 否 | 是 |

关键规则：

- `色调` 与 调色盘 无关，避免将红绿偏移强行映射到二维色盘
- 锐化与调色盘无关
- `色调` 和 `锐化` 只允许在 参数模式 中调整
- 调色盘强度 不改变 色调 和 锐化

## 8. 风格入口与调色面板

### 8.1 入口与打开状态

- 风格（Style）入口放置在相机工具栏中
- 用户点击风格后进入统一界面；选择“滤镜”进入滤镜切换，选择“调色”打开调色面板
- 打开后隐藏底部快门区和模式条
- 取景框保持竖向 `3:4` 预览
- 调色面板与预览框底部衔接
- 参数变化实时作用到取景预览
- 进入调色后默认展示调色盘模式

### 8.2 滤镜切换

- 调色盘模式 下，底部只显示 调色盘强度
- 参数模式 下，底部显示 7 个参数 图标 和当前参数 滑杆

用户点击 预览 区域时：

- 收起 调色面板
- 恢复快门区和模式条
- 当前 调色 参数继续生效
- 当前结果默认保存，不需要点击 Done

## 9. 两种编辑模式

### 9.1 模式原则

调色盘模式 与 参数模式 是两种显式切换、互不同时编辑的模式。

核心原则：

- 当前模式独占编辑权
- 模式切换按钮 是模式切换的唯一明确入口
- 调色盘模式 不展示独立参数入口
- 参数模式 下 调色盘和强度 不可调
- 最终保存依赖 7 个 调色 参数
- 不维护调色盘偏移量或参数滑杆偏移量

### 9.2 调色盘模式

调色盘模式 是打开 调色面板 后的默认模式。

可编辑控件：

- 调色盘
- 调色盘强度

不可见或不可编辑控件：

- Parameter Icon Rail
- 参数滑杆

写入规则：

- 调色盘 写入 `Contrast / Saturation / Warmth`
- 调色盘强度统一缩放上述 3 个参数的贡献
- `色调 / ``锐化` 保持当前最终值，不受 调色盘模式 操作影响

### 9.3 参数模式

用户点击 模式切换按钮 进入 参数模式。

进入后：

- 调色盘 缩小并降低视觉强调
- 调色点隐藏
- 调色盘和调色盘强度 不可编辑
- 显示 7 个参数 图标
- 显示当前参数名称、最终值和 滑杆
- 默认打开上次选中的参数；首次进入默认打开 Contrast

用户可以：

- 拖动 滑杆 直接调节当前最终参数
- 点击其他参数 图标 切换参数
- 点击 模式切换按钮 返回 调色盘模式

### 9.4 模式切换

#### 调色盘模式 -> 参数模式

- 切换瞬间不主动重算参数
- 当前 7 个最终参数作为 滑杆 初始值
- 调色盘和强度 停止写入
- 滑杆 开始直接写入选中的最终参数

#### 参数模式 -> 调色盘模式

- 切换瞬间保留当前 7 个参数和预览效果
- 系统可根据当前参数近似还原调色点位置
- UI 反推只用于控件定位，切换瞬间不得重算最终参数
- 色调 和 锐化 始终保持 参数模式 中的最终值
- 用户再次拖动调色盘或强度后，调色盘模式重新计算其负责的 3 个参数

由于独立参数与上层控件不是完整一一映射，用户重新操作 调色盘模式 时允许出现轻微预览变化。

## 10. 参数映射

### 10.1 底层真值

最终效果真值为 7 个 调色 参数：

```JSON
{
  "contrast": 0,
  "saturation": 0,
  "warmth": 0,
  "tint": 0,
  "sharpen": 0,
  "grain": 0,
  "vignette": 0
}

```

调色盘和调色盘强度 是前端控制层，不作为唯一效果真值。

### 10.2 调色盘强度

调色盘强度 范围：

```Plain Text
strength: 0 到 100
默认值：70

```

统一线性函数：

```Plain Text
实际贡献值 = 控件输入值 × 参数最大映射系数 × strength / 100

```

状态含义：

| 强度 | 含义 |
|-|-|
| 0 | 调色盘的参数贡献为 0 |
| 70 | 对应当前原型已验证的默认效果 |
| 100 | 达到各参数设定的最大映射贡献 |

强度只缩放调色盘负责的参数，不影响色调和锐化。

### 10.3 调色盘映射

调色盘 坐标：

```Plain Text
x: -100 到 +100，左侧偏冷，右侧偏暖
y: -100 到 +100，下方偏柔和，上方偏浓郁

```

当前原型映射：

| 参数 | 最大映射函数 | 强度 70 时的边缘贡献 |
|-|-|-|
| Warmth | `x × 1.0 × strength / 100` | 约 `±70` |
| Contrast | `y × 1.0 × strength / 100` | 约 `±70` |
| Saturation | `y × 0.714 × strength / 100` | 约 `±50` |
| 色调 | 不映射 | 不受影响 |
| 锐化 | 不映射 | 不受影响 |

说明：

- 调色盘 使用绝对坐标，不使用连续增量累加
- 默认 强度 70 保持此前原型的弱映射效果
- Saturation 继续使用弱映射，避免色盘顶部直接产生过度饱和效果
- 最大映射系数需要由影像团队基于实机效果进一步标定

### 10.4 参数滑杆

参数模式 下，滑杆 直接写入对应最终参数，不经过 调色盘强度：

| 参数 | 范围 |
|-|-|
| Contrast | -100 到 +100 |
| Saturation | -100 到 +100 |
| Warmth | -100 到 +100 |
| 色调 | -100 到 +100 |
| 锐化 | 0 到 100 |
| Grain | 0 到 100 |
| Vignette | 0 到 100 |

## 11. 重置规则

点击 重置 后：

- 调色盘 回到中心点
- 调色盘强度 回到默认值 `70`
- 7 个 调色 参数恢复默认值 `0`
- 模式回到 调色盘模式
- 取景预览恢复默认效果

重置 不承担关闭 调色面板 的职责。

## 12. 预设与兼容

### 12.1 保存策略

预设 必须保存最终 7 个 调色 参数。交互状态可作为可选元数据保存：

```JSON
{
  "tuning": {
    "contrast": 18,
    "saturation": 13,
    "warmth": 20,
    "tint": -1,
    "sharpen": 10,
    "grain": 40,
    "vignette": 44
  },
  "tuning_ui": {
    "mode": "palette",
    "palette_strength": 70,
    "palette": {
      "x": 28,
      "y": 26
    },
    "selected_parameter": "contrast"
  }
}
```

- `tuning` 是最终效果真值
- `tuning_ui` 是可选交互状态元数据
- 不保存调色盘偏移量或滑杆偏移量

### 12.2 老项目兼容

- 老项目只读取 `tuning` 即可还原最终效果
- 新项目可读取 `tuning_ui` 还原模式、强度 和 UI 状态
- 缺少 `palette_strength` 时，默认使用 `70`
- 缺少 `tuning_ui` 时，可以中性位置或粗略反推方式展示控件
- UI 状态反推不得在打开或切换模式时改变最终效果真值
- 老数据中已有 锐化 时继续读取和保留

### 12.3 预设展示

- 预设 卡片中仅展示最终参数，不展示 调色盘 点位
- 预设 配置页面中需要展示 调色盘
- 调色盘强度 建议在 预设 配置页面中展示

## 13. 与现有调色管线的关系

当前交互范围对应的处理顺序建议为：

```Plain Text
Warmth -> 色调 -> Contrast -> Saturation -> 锐化 -> Grain -> Vignette

```

- Warmth / 色调 先确定底色
- Contrast / Saturation 形成主要色调效果
- 锐化 在主要色彩调整后处理
- Grain 位于主要画面调整之后
- Vignette 最后处理

最终处理顺序需要开发与影像团队结合现有算法管线确认。

## 15. 非功能要求

### 15.1 性能

- 调色盘、强度和参数滑杆调节时预览需实时响应
- 模式切换不得出现明显掉帧或延迟
- 实时相机预览下需确认 Grain、Vignette 和 锐化 的性能边界

### 15.2 可用性

- 调色盘的触控热区需满足单手操作
- 模式切换按钮 需明确表达当前所处模式
- 参数模式下需明确表达调色盘和强度当前不可调
- 调色盘模式 下不展示独立参数项，避免误解为可同时编辑
- 滑杆 展开后不得与其他控件重叠
- 调色面板 不得遮挡 `3:4` 预览 主体

### 15.3 首次使用引导

- 现有 调色 onboarding 页面需要更新
- Onboarding 需体现 调色盘模式 快速调整与 参数模式 深入调节的关系
- 需说明 强度 控制调色盘整体效果，不等于单一参数
- 具体文案、动效和触发频次待交互设计稿确认

## 16. 验收标准

### 16.1 基础状态

- 进入调色后默认展示调色盘模式
- 竖向 3:4 预览框正常展示
- 打开调色面板后隐藏快门区和模式条
- 左侧模式切换按钮可切换两种模式
- 点击预览框可收起面板并保留当前效果

### 16.2 滤镜切换

- 进入滤镜后，预览框缩小并显示遮罩、横向滤镜画廊和圆点指示器，界面无重叠或主体遮挡。
- 横向滑动时，选中卡片、滤镜名称、滤镜强度、圆点位置和实时预览保持一致。
- 切换滤镜后仍停留在风格界面，可继续调整强度或进入调色。
- 快速连续滑动和往返切换时，预览无明显错帧、旧效果残留或选中状态错乱。

### 16.3 调色盘模式

- 调色盘和强度均可实时调节预览
- 调色盘模式不显示独立参数图标和滑杆
- 强度默认值为 `70`
- 强度在 0、70、100 时符合线性映射规则
- 调色盘使用绝对坐标，不发生无限累加漂移
- 调整调色盘模式时，色调和锐化保持不变

### 16.4 参数模式

- 点击模式切换按钮可进入参数模式
- 显示 7 个参数图标、当前参数名称、最终值和滑杆
- 当前参数图标高亮
- 点击其他图标可切换参数
- 调色盘缩小并隐藏拖拽点
- 调色盘和强度 不可直接调节
- 7 个滑杆均直接写入对应最终参数
- 点击模式切换按钮可返回调色盘模式

### 16.5 重置与兼容

- 重置后恢复 7 个参数默认值
- 重置后将强度恢复为 `70`
- 重置 后返回 调色盘模式
- 预设保存最终 7 个参数
- 缺少强度数据时使用默认值 `70`
- 老项目可忽略 `tuning_ui` 并还原效果
