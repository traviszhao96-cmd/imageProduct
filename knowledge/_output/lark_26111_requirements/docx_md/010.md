## 2. 本次更新摘要

本轮根据开发沟通和原型验证，将 Tuning 收敛为两个显式切换、互不同时编辑的模式：

- 左侧新增 `Palette / Parameters` 模式切换按钮
- 默认进入 Palette Mode
- Palette Mode 隐藏独立参数入口，底部仅展示整体 `Strength`
- Strength 默认值为 `70%`，对应当前已验证的调色盘效果
- Strength 使用线性函数缩放 Color Palette 和 Vintage Control 的参数贡献
- Parameter Mode 恢复完整 7 项参数精调，包括 `Tint` 和 `Sharpen`
- `Tint` 和 `Sharpen` 与调色盘无关，只允许在 Parameter Mode 中调整
- 模式切换由明确按钮负责，不再依赖点击控件外区域自动返回
- Tuning 暂不合并 Filter，避免面板承担过多功能

## 3. 背景与决策

### 3.1 原功能问题

现有 Tuning 功能以多个独立参数 Slider 为主要交互。用户需要先理解 Contrast、Saturation、Warmth、Tint、Sharpen、Grain、Vignette 等参数分别代表什么，再判断应该调整哪个参数、调整方向以及调整幅度。

这种交互对熟悉影像后期的高级用户有效，但对大部分普通相机用户存在明显门槛：

- 参数名称专业，用户难以提前理解调整后的实际效果
- 单个参数只能描述局部变化，用户很难通过多个 Slider 快速建立完整风格
- 用户需要在参数之间反复切换并观察预览，试错路径较长
- 多项参数组合后容易产生过度调节，用户难以恢复到协调状态
- 功能虽然提供了较强能力，但复杂度会降低用户发现、尝试和持续使用的意愿

因此，本需求并不是简单替换 Slider 的视觉形式，而是希望重新设计普通用户进入调色功能后的第一层交互。

### 3.2 用户心智

普通用户使用相机调色时，通常先表达的是整体感受，例如：

```Plain Text
更暖一些、更冷一些、更浓郁一些、更柔和一些、更复古一些

```

用户往往不是从“我要将 Warmth 调到 +25、Contrast 调到 +18”开始思考。Color Palette 将多个底层参数组合成连续的视觉空间，用户可以直接通过位置和实时预览探索效果，更贴近普通用户对照片风格的理解方式。

Parameter Slider 仍然有价值，但更适合作为第二层高级能力，而不是所有用户进入功能后的默认起点。

### 3.3 行业方案判断

从当前主流手机相机和影像产品的发展趋势看，越来越多产品使用调色盘、二维风格空间、摄影风格或类似的组合控制方式，帮助用户快速改变照片整体观感。

这些已落地方案验证了以下方向：

- 用户更容易通过连续视觉空间理解不同风格方向
- 组合调节比逐项理解专业参数更适合作为相机拍摄态入口
- 简单入口与高级参数可以分层共存，而不需要同时暴露
- 实时预览是用户判断调色效果的主要反馈，不需要先理解参数原理

因此，Color Palette 不是为了移除专业参数能力，而是作为已经被更多厂商和产品验证过的低门槛交互方案，承担 Tuning 的默认入口。

### 3.4 方案决策

Color Palette 适合用户快速获得整体风格，Parameter Slider 适合高级用户精确调整。若两类控件同时修改相同参数，会产生跳变、offset、反向同步和解释成本。

此前尝试过以下方向：

1. Color Palette 与 Parameter Slider 同时可编辑，并维护 offset
2. Color Palette 与 Parameter Slider 互斥，但 Palette Mode 仍展示全部参数入口
3. 将 Filter、Filter Strength 和 Tuning 合并进同一面板

当前决定采用更明确的双模式结构：

```Plain Text
Palette Mode：用 Color Palette、Vintage Control 和 Strength 快速建立整体风格
Parameter Mode：用 7 个独立参数进行完整精调

```

该方案的核心取舍：

- 两种模式不同时编辑，降低控制关系复杂度
- Strength 只控制调色盘体系的贡献，不等于任何单一底层参数
- Tint 和 Sharpen 不强行加入 Color Palette 映射，避免色盘边缘产生不自然效果
- 模式切换后允许用户继续基于当前模式产生新的预览变化

## 4. 目标

- 降低 Tuning 使用门槛，让用户通过调色盘快速获得整体风格
- 用 Strength 为调色盘效果提供统一、可理解的强弱控制
- 保留完整参数精调能力，满足高级用户需求
- 避免 Color Palette 与 Parameter Slider 同时编辑造成跳变和同步复杂度
- 为未来扩展更多参数保留清晰边界
- 以 7 个最终 Tuning 参数作为效果保存和兼容基础

最终效果包含 7 个 Tuning 参数：

| 序号 | 参数 | 范围 | 受 Color Palette 影响 | 受 Vintage Control 影响 | Parameter Mode 可调 |
|-|-|-|-|-|-|
| 1 | Contrast | -100 到 +100 | 是 | 否 | 是 |
| 2 | Saturation | -100 到 +100 | 是 | 否 | 是 |
| 3 | Warmth | -100 到 +100 | 是 | 否 | 是 |
| 4 | Tint | -100 到 +100 | 否 | 否 | 是 |

- `Tint` 与 Color Palette 无关，避免将红绿偏移强行映射到二维色盘
- `Sharpen` 与 Color Palette、Vintage Control 均无关
- `Tint` 和 `Sharpen` 只允许在 Parameter Mode 中调整
- Palette Strength 不改变 Tint 和 Sharpen

## 8. Tuning Panel

### 8.1 入口与打开状态

- Tuning 入口放置在相机设置面板中
- 用户点击 Tuning 后打开 Tuning Panel
- 打开后隐藏底部快门区和模式条
- 取景框保持竖向 `3:4` 预览
- Tuning Panel 顶部与 preview 底部承接
- 参数变化实时作用到取景预览
- 默认进入 Palette Mode

### 8.2 组件结构

Tuning Panel 包含：

1. Grabber
2. Reset Button
3. Mode Switch
4. Color Palette
5. Vintage Control
6. Palette Strength
7. Parameter Icon Rail
8. Parameter Slider

交互建议：

- Reset 位于左上角，仅负责恢复默认值
- Mode Switch 位于 Color Palette 左侧，明确表示当前编辑模式
- Palette Mode 下，底部只显示 Palette Strength
- Parameter Mode 下，底部显示 7 个参数 icon 和当前参数 Slider
- 不显示 Done 按钮

### 8.3 收起与保存

用户点击 preview 区域时：

- 收起 Tuning Panel
- 恢复快门区和模式条
- 当前 Tuning 参数继续生效
- 当前结果默认保存，不需要点击 Done

## 9. 两种编辑模式

### 9.1 模式原则

Palette Mode 与 Parameter Mode 是两种显式切换、互不同时编辑的模式。

核心原则：

- 当前模式独占编辑权
- Mode Switch 是模式切换的唯一明确入口
- Palette Mode 不展示独立参数入口
- Parameter Mode 下 Color Palette、Vintage Control 和 Strength 不可调
- 最终保存依赖 7 个 Tuning 参数
- 不维护 Palette offset、Vintage offset 或参数 Slider offset

### 9.2 Palette Mode

Palette Mode 是打开 Tuning Panel 后的默认模式。

可编辑控件：

- Color Palette
- Vintage Control
- Palette Strength

不可见或不可编辑控件：

- Parameter Icon Rail
- Parameter Slider

写入规则：

- Color Palette 写入 `Contrast / Saturation / Warmth`
- Vintage Control 写入 `Grain / Vignette`
- Palette Strength 统一缩放上述 5 个参数的贡献
- `Tint / Sharpen` 保持当前最终值，不受 Palette Mode 操作影响

### 9.3 Parameter Mode

用户点击 Mode Switch 进入 Parameter Mode。

进入后：

- Color Palette 缩小并降低视觉强调
- Vintage Control 缩短并降低视觉强调
- Palette Point 和 Vintage knob 隐藏
- Color Palette、Vintage Control 和 Palette Strength 不可编辑
- 显示 7 个参数 icon
- 显示当前参数名称、最终值和 Slider
- 默认打开上次选中的参数；首次进入默认打开 Contrast

用户可以：

- 拖动 Slider 直接调节当前最终参数
- 点击其他参数 icon 切换参数
- 点击 Mode Switch 返回 Palette Mode

### 9.4 模式切换

#### Palette Mode -> Parameter Mode

- 切换瞬间不主动重算参数
- 当前 7 个最终参数作为 Slider 初始值
- Color Palette、Vintage Control 和 Strength 停止写入
- Slider 开始直接写入选中的最终参数

#### Parameter Mode -> Palette Mode

- 切换瞬间保留当前 7 个参数和预览效果
- 系统可根据当前参数近似还原 Palette Point 和 Vintage Control 的位置
- UI 反推只用于控件定位，切换瞬间不得重算最终参数
- Tint 和 Sharpen 始终保持 Parameter Mode 中的最终值
- 用户再次拖动 Color Palette、Vintage Control 或 Strength 后，Palette Mode 重新计算其负责的 5 个参数

由于独立参数与上层控件不是完整一一映射，用户重新操作 Palette Mode 时允许出现轻微预览变化。

## 10. 参数映射

### 10.1 底层真值

最终效果真值为 7 个 Tuning 参数：

```JSON
{
  "contrast": 0,
  "saturation": 0,
  "warmth": 0,
  "tint": 0,
  "sharpen": 0,
  "grain": 0,
  "vignette": 0
}

```

Color Palette、Vintage Control 和 Palette Strength 是前端控制层，不作为唯一效果真值。

### 10.2 Palette Strength

Palette Strength 范围：

```Plain Text
strength: 0 到 100
默认值：70

```

统一线性函数：

```Plain Text
实际贡献值 = 控件输入值 × 参数最大映射系数 × strength / 100

```

状态含义：

| Strength | 含义 |
|-|-|
| 0 | Color Palette 和 Vintage Control 的参数贡献为 0 |
| 70 | 对应当前原型已验证的默认效果 |
| 100 | 达到各参数设定的最大映射贡献 |

Strength 只缩放 Color Palette 和 Vintage Control 所负责的参数，不影响 Tint 和 Sharpen。

### 10.3 Color Palette 映射

Color Palette 坐标：

```Plain Text
x: -100 到 +100，左侧偏冷，右侧偏暖
y: -100 到 +100，下方偏柔和，上方偏浓郁

```

当前原型映射：

| 参数 | 最大映射函数 | Strength 70 时的边缘贡献 |
|-|-|-|
| Warmth | `x × 1.0 × strength / 100` | 约 `±70` |
| Contrast | `y × 1.0 × strength / 100` | 约 `±70` |
| Saturation | `y × 0.714 × strength / 100` | 约 `±50` |
| Tint | 不映射 | 不受影响 |
| Sharpen | 不映射 | 不受影响 |

说明：

- Color Palette 使用绝对坐标，不使用连续增量累加
- 默认 Strength 70 保持此前原型的弱映射效果
- Saturation 继续使用弱映射，避免色盘顶部直接产生过度饱和效果
- 最大映射系数需要由影像团队基于实机效果进一步标定

### 10.4 Vintage Control 映射

Vintage Control 范围：

```Plain Text
vintage: 0 到 100

```

当前原型映射：

| 参数 | 最大映射函数 | Strength 70 且 Vintage 100 时 |
|-|-|-|
| Grain | `vintage × 0.714 × strength / 100` | 约 `50` |
| Vignette | `vintage × 0.786 × strength / 100` | 约 `55` |

说明：

- Vintage Control 与 Palette Strength 共用整体强度
- 默认强度下避免 Grain 和 Vignette 被直接拉到极值

### 10.5 Parameter Slider

Parameter Mode 下，Slider 直接写入对应最终参数，不经过 Palette Strength：

| 参数 | 范围 |
|-|-|
| Contrast | -100 到 +100 |
| Saturation | -100 到 +100 |
| Warmth | -100 到 +100 |
| Tint | -100 到 +100 |
| Sharpen | 0 到 100 |
| Grain | 0 到 100 |
| Vignette | 0 到 100 |

## 11. Reset 规则

点击 Reset 后：

- Color Palette 回到中心点
- Vintage Control 回到 `0`
- Palette Strength 回到默认值 `70`
- 7 个 Tuning 参数恢复默认值 `0`
- 模式回到 Palette Mode
- 取景预览恢复默认效果

Reset 不承担关闭 Tuning Panel 的职责。

## 12. Preset 与兼容

### 12.1 保存策略

Preset 必须保存最终 7 个 Tuning 参数。交互状态可作为可选元数据保存：

```JSON
{
  "tuning": {
    "contrast": 18,
    "saturation": 13,
    "warmth": 20,
    "tint": -1,
    "sharpen": 10,
    "grain": 40,
    "vignette": 44
  },
  "tuning_ui": {
    "mode": "palette",
    "palette_strength": 70,
    "palette": {
      "x": 28,
      "y": 26
    },
    "vintage": {
      "value": 80
    },
    "selected_parameter": "contrast"
  }
}

```

- `tuning` 是最终效果真值
- `tuning_ui` 是可选交互状态元数据
- 不保存 Palette offset、Vintage offset 或 Slider offset

### 12.2 老项目兼容

- 老项目只读取 `tuning` 即可还原最终效果
- 新项目可读取 `tuning_ui` 还原模式、Strength 和 UI 状态
- 缺少 `palette_strength` 时，默认使用 `70`
- 缺少 `tuning_ui` 时，可以中性位置或粗略反推方式展示控件
- UI 状态反推不得在打开或切换模式时改变最终效果真值
- 老数据中已有 Sharpen 时继续读取和保留

### 12.3 Preset 展示

- Preset 卡片中仅展示最终参数，不展示 Color Palette 点位
- Preset 配置页面中需要展示 Color Palette
- Palette Strength 建议在 Preset 配置页面中展示
- 是否展示 Vintage Control，随最终交互稿确认

## 13. 与现有 Tuning 管线关系

当前交互范围对应的处理顺序建议为：

```Plain Text
Warmth -> Tint -> Contrast -> Saturation -> Sharpen -> Grain -> Vignette

```

- Warmth / Tint 先确定底色
- Contrast / Saturation 形成主要色调效果
- Sharpen 在主要色彩调整后处理
- Grain 位于主要画面调整之后
- Vignette 最后处理

最终处理顺序需要开发与影像团队结合现有算法管线确认。

## 15. 非功能要求

### 15.1 性能

- Color Palette、Vintage Control、Strength 和 Parameter Slider 调节时预览需实时响应
- 模式切换不得出现明显掉帧或延迟
- 实时相机预览下需确认 Grain、Vignette 和 Sharpen 的性能边界

### 15.2 可用性

- Color Palette 和 Vintage Control 的触控热区需满足单手操作
- Mode Switch 需明确表达当前所处模式
- Parameter Mode 下需明确表达 Color Palette 和 Vintage Control 当前不可调
- Palette Mode 下不展示独立参数项，避免误解为可同时编辑
- Slider 展开后不得与其他控件重叠
- Tuning Panel 不得遮挡 `3:4` preview 主体

### 15.3 Onboarding

- 现有 Tuning onboarding 页面需要更新
- Onboarding 需体现 Palette Mode 快速调整与 Parameter Mode 深入调节的关系
- 需说明 Strength 控制调色盘整体效果，不等于单一参数
- 具体文案、动效和触发频次待交互设计稿确认

## 16. 验收标准

### 16.1 基础状态

- 默认进入 Palette Mode
- 竖向 `3:4` preview 正常展示
- 打开 Tuning Panel 后隐藏快门区和模式条
- 左侧 Mode Switch 可切换两种模式
- 点击 preview 可收起面板并保留当前效果

### 16.2 Palette Mode

- Color Palette、Vintage Control 和 Strength 均可实时调节预览
- Palette Mode 不显示独立参数 icon 和 Slider
- Strength 默认值为 `70`
- Strength 0 / 70 / 100 符合线性映射规则
- Color Palette 使用绝对坐标，不发生无限累加漂移
- 调整 Palette Mode 时 Tint 和 Sharpen 保持不变

### 16.3 Parameter Mode

- 点击 Mode Switch 可进入 Parameter Mode
- 显示 7 个参数 icon、当前参数名称、最终值和 Slider
- 当前参数 icon 高亮
- 点击其他 icon 可切换参数
- Color Palette 和 Vintage Control 缩小并隐藏拖拽点
- Color Palette、Vintage Control 和 Strength 不可直接调节
- 7 个 Slider 均直接写入对应最终参数
- 点击 Mode Switch 可返回 Palette Mode

### 16.4 Reset 与兼容

- Reset 恢复 7 个参数默认值
- Reset 将 Strength 恢复为 `70`
- Reset 后返回 Palette Mode
- Preset 保存包含最终 7 个参数
- 缺少 Strength 数据时使用默认值 `70`
- 老项目可忽略 `tuning_ui` 并还原效果
