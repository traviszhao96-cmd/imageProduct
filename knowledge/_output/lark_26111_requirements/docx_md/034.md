# 一、背景

## 1.1 用户需求

在 26121 的用户画像中，我们可以看到有一部分极客用户和视频创作者群体；也有一部分用户需要明确的升级感。Log 功能不仅可以满足创作者和极客用户的实际创作需求，更可以增强用户对 Pro 机型的认知，建立明确的升级感。  
具体实例：对使用 Nothing Phone 的影像专业用户进行一对一访谈的过程中，问到为何不用我们的手机进行视频创作，用户明确指出，我们的视频没有 Log 模式，同时无法控制曝光和色彩，无法满足他的专业创作诉求。

## 1.2 产品定位

26121 的 KSP 方向是专业视频能力。Log 模式是目前旗舰影像手机中区分「普通视频」和「专业视频」的核心特性之一，对外能够直接支撑 Pro 属性的营销叙事，对内也为后续视频专业化方向建立了技术基础。

## 1.3 Log 是什么，对用户有什么价值

Log 是一条替代标准 Gamma 的对数编码曲线。标准视频（Rec.709）的 Gamma 是为「在屏幕上好看」设计的，高光区域码值少，传感器抓到的很多信息在 Tone Mapping 阶段就被丢掉了。Log 曲线压缩高光、拉升暗部，把更大的动态范围均匀地编码进码值空间里。

结果是：Log 画面看起来又灰又平，对比度低，饱和度低。**这是正常的——Log 素材不是给人直接看的，是给后期调色用的原材料。**

- **调色空间更大**：在 DaVinci、Premiere 里可以大幅推拉曝光、做二级调色，不容易出现色阶断裂或高光崩掉
- **绕开机内破坏性处理**：机内的锐化、降噪、风格化 Tone Mapping 都是单向不可逆的操作，Log 模式让 ISP 更透明，把这些决策权交给用户

## 1.4 我们怎么做

我们已经有了 **10-bit 编码 + Rec.2020 色域**，这条硬件链路 HLG 和 Log 可以完全共用——编码器不关心传进来的是什么信号，它只是在编 10-bit 的数字。

HLG 和 Log 的本质区别，**仅仅是 ISP 侧用的那条 Gamma 曲线不同**。

所以从底层来说我们要做的事情有两件：

1. **定义一条 Log 曲线**，替换掉当前视频模式的 Gamma
2. **制作一个配套的 还原 LUT**，让用户在后期软件里能一键还原到正常画面

作为轻量级实现，曲线设计可以参考 **DJI D-Log M**。D-Log M 是一条相对温和的 Log 曲线，目标动态范围约 12–13 stops，对传感器底噪要求不像 S-Log3 那么激进，非常适合手机平台。色域配套 BT.2020，与我们现有的编码链路直接对齐。

# 二、竞品分析

> 主要注重与竞品如何运用 Log 功能，给用户带来什么便利性与价值

**三星**

视频模式：默认无任何 Log 选项，若在专业模式中开启 log 退出回到视频模式，会弹出“在视频模式中使用 Log” 提示，后在视频模式中也会出现 Log 选项

- 有 Lut 监看
- 无任何专业控制

专业模式：有单独视频专业模式，可开启 Log

- 有 Lut 监看，不支持烧录，预设 5 个 Lut，不支持导入
- 有直方图预览；有斑马纹和伪彩色两种曝光检测工具
- 有色调、高亮、阴影、饱和度、色彩 5 个调色工具

相册编辑：相册可识别 Log 视频，编辑内支持使用预设 Lut 快捷还原。



解读：将 Log 定义为专业功能，仅提供给专业用户使用；提供较多的曝光辅助功能和调色选项，致力于让用户能在拍摄时有充足的信心，对严肃创作的有较多帮助。但便利性略显不足，分享流程过长。



**苹果（原相机）**

视频模式：格式中可开启 Log

- 无 Lut 监看
- 无控制选项
- 仅可录制 ProRes 格式

专业模式：原相机无专业模式，但苹果提供官方的专业视频 App - Final Cut Camera，可提供多重专业控制

- 可开启 Lut 监看
- 可选择编码格式
- 有过曝指示器与峰值对焦

相册编辑：可识别 ProRes Log 标签，无法进行编辑



解读：原相机中仅做“功能展示”，无实际使用价值，需配合一方或三方的专业视频 App 使用。一方 App Final Cut Camera 重点在“多机位”和 Final Cut 生态，提供比三星更进一步的专业创作流程



**飓风相机（仅支持苹果）**

简易模式与专业模式均可拍摄 Log 视频。

- 有 Lut 监看，可直接烧录 Lut，一键录制已套 Lut 的视频
- 有波形图与直方图预览
- 不可导入 Lut，也无自主调色工具

素材库：可快捷添加 Lut 后导出到系统相册；可快捷导出为实况图

特色功能：Log 实况 - 利用 Log 视频流，录制 3s 实况，可提前选好 Lut，实现更高级的影调



解读：苹果三方专业视频 App 中使用门槛最低的，特色的 Log 实况和影调烧录功能均偏向即时分享，用Apple Log 的底层能力+影视飓风调色师的高审美，让普通用户可以利用好 Log 的能力，轻松的拍出更具质感的视频，快速出片。

# 附录：术语速查

| **术语** | **含义** |
|-|-|
| **Log / Log Gamma** | 对数编码曲线，用于将线性光信号压缩到有限码值空间，保留更多高光和暗部细节 |
| **Tone Mapping** | 将传感器线性信号映射到目标显示范围的过程，带有主观判断 |
| **HLG** | Hybrid Log-Gamma，一种 HDR 交付格式，兼容 HDR 屏和 SDR 屏，ITU-R BT.2100 标准 |
| **LUT** | Look Up Table，颜色映射表。Conversion LUT 用于格式还原，Creative LUT 用于风格定义 |
| **Rec.709** | 标准高清视频色彩空间，SDR 屏幕的标准输出格式 |
| **Rec.2020** | 超高清视频色彩空间，色域远大于 Rec.709，HLG 和 Log 均基于此色域 |
| **10-bit** | 视频编码位深，Log 模式的必要条件，8-bit Log 无实用价值 |
| **动态范围 / stops** | 传感器或编码格式能表达的最亮与最暗之间的比值，每增加 1 stop 表示亮度范围翻倍 |
