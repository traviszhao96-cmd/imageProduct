## 1. 背景与目标

### 问题陈述

当前的 preset 功能绑定了模式、焦段等全部相机设置，用户只想应用一套调色参数（滤镜 + tuning + EV）时，却被迫设置所有功能，使用门槛过高。同时，普通用户面对数十个滤镜选项时缺乏选择依据，不知道该用哪个。

### 证据与数据

- 竞品参考：DOKA 相机已上线场景识别 + 滤镜推荐功能，根据画面内容分析后推荐合适的滤镜并给出理由
- [TBD — 需补充用户反馈/埋点数据]

### 目标用户与场景

- 用户角色：普通拍照用户，不希望手动调试参数
- 核心场景：打开相机 → 对准拍摄目标 → 一键获得适合当前场景的调色方案
- 使用频率：[TBD — 需数据验证]

### 预期收益

1. 让用户轻松应用合适的效果风格，提升照片和视频拍摄的满意度
2. 降低 preset 功能的使用门槛，让用户可以一键快速应用合适的 preset

## 3. 功能定义

### 功能描述

- 功能名称：AI Preset
- 一句话描述：基于当前拍摄场景的实时分析，自动推荐合适的滤镜+调色 preset，用户一键应用

### 范围

**In Scope:**

- 相机端 AI 场景分析 → 滤镜 + 调色 preset 推荐
- 创意 / 稳定两种推荐风格
- 推荐过程"思维链"展示（可选，非强制）

**Out of Scope:**

| 不做什么 | 原因 | 未来是否考虑 |
|-|-|-|
| 姿势/构图引导 | 聚焦调色推荐，非本期目标 | 是 |
| 仿色/追色功能 | 聚焦调色推荐，非本期目标 | 是 |
| 相册端仿色提取 | 聚焦调色推荐，非本期目标 | 是 |

### 适用模式/入口

- 相机预览页 → AI Preset 按键（位于 preset 按键附近）
- 覆盖所有拍摄模式、所有焦段

*正常路径：*

1. 用户在相机预览页点击"AI Preset"按键
2. 系统分析当前场景（光线、色系、主体元素），**可选**展示"思维链"过程：

3. 用户选择其中一个卡片，滤镜+调色效果立即应用到预览

*边界：*

- 推荐的 preset 包含滤镜、模式、焦段
- 三个推荐卡片必须保证多样性，不可全为同一滤镜

### R2 · 推荐风格选择-待定

优先级：Should-have

在相机设置中支持选择 AI Preset 的推荐风格：创意模式或稳定模式（可能，根据实际效果待定）。

*正常路径：*

- **创意模式**（默认）：放宽滤镜与调色边界，三个推荐卡片覆盖不同情绪维度（如冷峻、复古、高调清新），风格差异明显
- **稳定模式**：收紧参数边界，锁定经典模拟胶片或标准调色域，三个卡片为同一基调下的微调（如均为胶片风格，但色温/色调/曝光不同）

*边界：*

- 用户未选择时默认为创意模式
- 切换风格后需重新点击 AI Preset 触发推荐

## 5. 方案说明

### 核心行为

1. 用户在相机预览页点击"AI Preset"
2. 系统实时分析当前预览帧 → 提取场景特征（光线方向与强度、色温、主体元素）
3. 场景特征输入推荐模型 → 输出 3 个预设方案，每个方案包含：滤镜类型 + 调色参数（对比度、饱和度、色温、曝光补偿等）+ 预设名称
4. 底部弹出推荐卡片，用户滑动选择 → 点击应用

### 效果约束

**合理性：**

- 场景逻辑约束：不可在"正午强光"场景推荐"暗调夜景"参数，不可在"自然风光"场景强加"赛博朋克/霓虹"高饱和度人工色差
- 单项参数（对比度、高光剥离、阴影色调）调整幅度设硬性上下限，防止色阶断层或噪点激增

**多样性：**

- 同一场景 3 个推荐不可全为同一滤镜
- 创意模式下覆盖不同情绪维度，避免同质化
