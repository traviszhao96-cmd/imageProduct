## Why Action Mode Has No Toolbar Rows

The current canonical KB builder creates Toolbar rows only with `模式=照片`:

- `Flash`
- `Timer`
- `HDR`
- `Exposure`
- `Filter`
- `Tuning`
- `Motion Photo`
- `Motion Photo cover HDR`
- `Quality`
- `Grid`
- `Ratio`
- `Watermark`
- `More settings`
- `Glyph Mirror`

The FL generator expands rows strictly from each KB row's mode scope. Therefore Action mode only receives rows whose KB scope includes `运动`, such as Preview and Zoom. It does not inherit Photo Toolbar rows.

However, `knowledge/reference/action.md` already says independent Action mode supports:

- Timer
- HDR
- Exposure
- Filter
- Tuning
- Grid / Ratio
- Watermark
- Ultra HDR
- Night transient switch

And does not support:

- Flash
- Auto Tone
- Motion Photo
- High pixel / 50MP
- Beauty / Retouch
- Bokeh

Conclusion: this is a generator / KB scope gap, not a product rule saying Action has no Toolbar.

## Suggested Fix

Add Action-specific rows from `knowledge/reference/action.md` instead of blindly expanding all Photo Toolbar items.
