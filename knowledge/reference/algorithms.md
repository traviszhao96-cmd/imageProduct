# 算法链路（25131）

## 核心算法

### Raw HDR（自研 HDR 检测）
- 触发: 主摄/前置 lux < 320, 超广角 lux < 300
- 与夜景互斥（通过 luxindex 阈值切分）
- 后置双摄均支持

### 夜景
- 触发: lux > 300-350（依模式和摄像头）
- 超级夜景: TF SN 算法
- 与 HDR 互斥
- 视频夜景: 仅平台降噪，无独立算法

### CFR（Color Fringe Removal / 紫边去除）
- 触发: lux < 250 AND HDR 生效
- 退出: lux > 280 OR HDR 关闭
- 需做进出平滑，V3 验收锁定阈值
- 25131 人不做叠加 CFR（体验小组决策）

### SR（Super Resolution / 超分）
- YUV 方案: zoom >= 4x 启动
- RAW 方案: zoom >= 2x 启动
- 夜景 SR: lux > 320
- HDSR: 达到 SR 条件 AND 检测到 HDR

### FRT（Face Restoration Technology / 人脸清晰度增强）
- 内部人脸检测触发
- 支持: 拍照/夜景/人像/高像素

### EIS（电子防抖）
- 拍照: PZS 在 zoom >= 4x 启动
- 视频: 默认开启
- PZS 与 Nona 不冲突，可叠加

### SAT（Smooth Angle Transition / 平滑镜头切换）
- 默认开启: 拍照/夜景/录像/延时
- 不适用: 人像/专业

### 美颜
- 用户触发 AND FD 检测到人脸
- 仅前置: 拍照/人像/夜景

### XDR（Ultra HDR）
- 后置 AND RAW 算法触发（RAW HDR / 夜景）
- 人像模式用户触发

### HW Remosaic（108M）
- 仅高像素模式，lux < 200
- 仅叠加: 滤镜 / CFR / FRT

## 算法互斥关系

| 组合 | 互斥 |
|------|------|
| HDR ↔ 夜景 | ✅ 互斥（lux 切分） |
| HDR ↔ 人像 HDR | 不同模式 |
| CFR ↔ 非 HDR 场景 | CFR 仅在 HDR 内生效 |
