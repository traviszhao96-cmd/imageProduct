# Tuning（调色）

## 概述

独立的手动调色功能，7 个参数按固定顺序叠加。入口：下拉工具栏 → 风格。

## 依赖

- 纯软件，无硬件限制
- 仅照片 + 人像 + 视频 1080P30fps
- 低端项目可能因性能与 HDR 互斥

## Pipeline 顺序（有先后依赖）

| 顺序 | 参数 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| 1 | 色温 Warmth | -100 ~ +100 | 0 | 必须先执行，定底色 |
| 2 | 色调 Tint | -100 ~ +100 | 0 | 必须先执行，定底色 |
| 3 | 对比度 Contrast | -100 ~ +100 | 0 | |
| 4 | 饱和度 Saturation | -100 ~ +100 | 0 | 拉到 -100 会归零前面所有色彩偏移，确保纯净黑白 |
| 5 | 锐度 Sharpen | 0 ~ 100 | 0 | |
| 6 | 颗粒 Grain | 0 ~ 100 | 0 | 必须在锐度之后，否则噪点被锐化变脏 |
| 7 | 暗角 Vignette | 0 ~ 100 | 0 | 最后做遮罩，防止被对比度破坏过渡 |

## 规则

- 支持永久记忆上次设置
- Reset 按钮一键重置全部为 0
- 切换模式/前后置 → 恢复默认效果（不支持跨模式记忆）
- 与滤镜可叠加使用（Tuning 在 ISP 层？滤镜在 LUT 层？— [TBD: 需确认叠加顺序]）
- 可存入 Preset

## 竞品对比

| 竞品 | 覆盖范围 | Tuning 能力 |
|------|------|------|
| OPPO 大师模式 | 仅专业模式 | 10 滤镜 + 锐度/暗角/柔光 |
| 小米徕卡 | 仅专业模式 | 曝光/对比度/饱和度/色温等 |
| Sony 创意外观 | **所有模式** | 10 风格 + 对比度/高光/阴影/锐度等 |
| **Nothing** | 照片+人像+视频 | **7 参数全部模式可用** |

Nothing 的优势：不在专业模式独占，所有模式可用。
