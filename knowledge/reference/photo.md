# Photo（拍照模式）

## 概述

最高频的拍摄模式，支持最广的功能范围。所有后置摄像头（超广角 + 主摄）和前置摄像头可用。

## 依赖

- 硬件: 超广角/主摄摄像头
- 算法: Raw HDR、夜景、FRT、SR、美颜、运动检测
- 平台: 纯软件部分默认支持，硬件相关见每摄像头能力

## 交互位置

见 `feature-tree.md`:
- 预览框: 场景检测 / 对焦 / 变焦
- AE/AF Box: Touch AE/AF / Face AF / EV
- Zoom: 光变点 / 滑动变焦 / 双指缩放 / SAT
- Shutter: 拍照 / 连拍 / 动态照片
- Toolbar: HDR / 闪光灯 / 滤镜 / Tuning / 照片风格 / 比例 / ...
- Settings: 水印 / 网格 / 水平仪 / ...

## 超广角 vs 主摄差异总结

| 主摄支持但 UW 不支持 | 原因 |
|------|------|
| OIS | 硬件: GC08A8 无 VCM |
| EIS / PZS | 硬件: 无 OIS |
| 高像素 50MP | 硬件: 8MP 非 Quad Bayer |
| 光学畸变矫正 | 仅 UW 需要 |
| SR (RAW) | 硬件限制 |
| PDAF | 硬件: UW 固定对焦 |

## 算法叠加顺序

```
Raw HDR/夜景
  → CFR（条件叠加）
  → FRT（人脸场景）
  → SR（zoom 条件）
  → 滤镜（用户触发）
  → Tuning（用户触发）
  → 水印（用户触发）
  → XDR（RAW 算法叠加）
```
