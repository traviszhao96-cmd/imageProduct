# Action Mode（运动抓拍）

## 概述

独立运动抓拍模式，通过运动检测 + 高速快门策略，提升运动场景成片率。另在照片模式下支持轻量运动检测。

## 依赖

- 算法: 运动检测模型、高速快门策略
- 硬件: 摄像头帧率 ≥ 60fps（低于 60fps 效果差），直接挂钩视频最大规格
- 平台: 纯软件

帧率对照:
| 摄像头 | 视频最大规格 | 帧率 | Action Mode 效果 |
|------|------|------|------|
| 主摄 | 1080P60fps | 60fps | ✅ 可用 |
| 超广角 (GC08A8) | 仅 1080P30fps | 30fps | ⚠️ 效果受限 |
| 前置 | 仅 1080P30fps | 30fps | ⚠️ 效果受限 |

> 25131 超广角和前置因 budget sensor 帧率限制，Action Mode 在这些摄像头上效果下降。推荐仅在主摄和长焦（≥60fps）上使用。

## 功能范围

### 独立 Action 模式

入口: 模式选择栏最左侧（Portrait 左侧）

焦段: 超广角 / 主摄 / 长焦，不支持滑动变焦仅点切（23112: 仅 1x & 3x）

模式内互斥（不支持）:
| 功能 | 原因 |
|------|------|
| 闪光灯 | 抓拍场景不需要 |
| Auto Tone | 与高速快门冲突 |
| Motion Photo | 与高速快门冲突 |
| 高像素 50MP | 性能限制 |
| 美颜 (Retouch) | 性能限制 |
| 虚化 (Bokeh) | 无场景关联 |

模式内支持:
| 功能 | 说明 |
|------|------|
| 倒计时 | ✅ |
| HDR | ✅ |
| 手动曝光 | ✅ |
| 滤镜 | ✅ |
| Tuning | ✅ |
| 网格 / 比例 | ✅ |
| 水印 | ✅ |
| Ultra HDR | ✅ |
| 夜景（暂态） | ✅ |

### 照片模式轻量抓拍

入口: Toolbar → 运动抓拍开关

焦段: 前置 / 超广角 / 主摄 / 长焦，全焦段

功能: 检测到运动 → 提升快门速度 → 降低运动模糊

互斥: 无

## 运动检测逻辑

1. 检测画面中的物体运动
2. 自动提升快门速度（具体值 [TBD — 需算法确认]）
3. Action 模式比 Photo 模式的策略更激进

## 覆盖矩阵

| | Photo 轻量抓拍 | Action 模式 |
|------|------|------|
| 触发 | 检测到运动 + 用户开启 | 进入模式即启用 |
| 快门策略 | 适度提升 | 激进提升 |
| 焦段 | 全焦段 + 前摄 | 超广角/主摄/长焦 |
| 变焦 | 全部 | 仅点切 |
| Preset | - | Cricket/Sports |

## Preset 关联

- Cricket Preset（印度）→ 底层设为 Action 模式，快门 ≤ 1/500
- Sports Preset（ROW）→ 复用 Cricket 配置
- 25131 新增 Sports Preset
