> 基线: 25131 算法体系，26121 对齐 25111 Pro

## 1. 平台与硬件概要

| 维度 | 26111 (5a base) | 26121 (5a Pro) |
|------|----------------|-----------------|
| SoC | SM7635 | SM7750 |
| 主摄 | 200M HP5 | 50M IMX896 (OIS) |

### 关键约束

- **26111 无长焦** → SAT、长焦 SR/HDR/夜景、AIGC SR 不适用
- **26111 SM7635** → 参考 25111 Basic 同平台能力：
  - ❌ 4K 任何帧率、❌ 1080P60、❌ Video HDR 算法、❌ AIGC SR
  - ⚠️ ISZ/EIS 行为取决于 sensor（HP5 200MP 裁切空间大，待确认）
- **26111 主摄无 OIS** → 仅 EIS，200MP sensor 裁切空间充足
- **26121 相机硬件 = 25111 Pro** → 算法基线参考 [25111 Feature List v2.3]
  - ✅ 4K30 (主摄+长焦，无超广角)、✅ 1080P60、✅ Video HDR 算法
  - ❌ 4K60、❌ 运动抓拍（25111 不支持，5a P0 新增）
- **26121 前置 = KD1**（25111 Pro Cam Spec 写 JNS，Front sheet 写 KD1；26121 确认 KD1）

## 4. 分算法详细说明

### 4.1 Raw HDR（自研 HDR 检测）

- **触发**: 主摄/前置 lux < 320, 超广角 lux < 300
- **互斥**: 与夜景通过 luxindex 阈值切分
- **26111**: 主摄 + 超广角 + 前置均支持
- **26121**: 主摄 + 超广角 + 长焦 + 前置均支持

### 4.2 夜景

- **触发**: lux > 300-350（依模式和摄像头）
- **超级夜景**: TF SN 算法
- **26111**: 主摄 + 超广角 + 前置
- **26121**: 主摄 + 超广角 + 长焦 + 前置
- 与 HDR 互斥

### 4.3 CFR（Color Fringe Removal / 紫边去除）

- **触发**: lux < 250 AND HDR 生效
- **退出**: lux > 280 OR HDR 关闭
- 需做进出平滑
- 5a 不做叠加 CFR（延续 25131 决策）

### 4.4 SR（Super Resolution / 超分）

- **YUV 方案**: zoom ≥ 4x 启动
- **RAW 方案**: zoom ≥ 2x 启动
- **夜景 SR**: lux > 320
- **26111**: 仅主摄（无长焦）
- **26121**: 主摄 + 长焦均支持

### 4.5 FRT（Face Restoration Technology）

- 内部人脸检测触发
- 支持模式: 拍照/夜景/人像/高像素
- 两个设备均支持

### 4.6 EIS（电子防抖）

- **拍照**: PZS 在 zoom ≥ 4x 启动
- **视频**: 默认开启
- **26111**: 主摄无 OIS，200MP sensor 裁切空间可覆盖 EIS 需求
- **26121**: OIS + EIS 可叠加

### 4.7 SAT（Smooth Angle Transition / 平滑镜头切换）

- **26111**: ❌ 单摄不支持
- **26121**: ✅ 主摄 ↔ 长焦
- 默认开启: 拍照/夜景/录像/延时
- 不适用: 人像/专业

### 4.8 美颜

- 用户触发 AND FD 检测到人脸
- 仅前置: 拍照/人像/夜景
- 5a 升级为"自然质感人像"（P0）

### 4.9 XDR（Ultra HDR）

- 后置 AND RAW 算法触发（RAW HDR / 夜景）
- 人像模式用户触发
- 两个设备均支持

### 4.10 HW Remosaic（高像素）

- **26111**: 200MP 模式，对齐 JN1 50MP 方案，lux < 200
- **26121**: 50MP 模式，对齐 25111 Pro
- 仅叠加: 滤镜 / CFR / FRT
- **新增**: 运动抓拍叠加（P0）

### 4.11 运动抓拍（P0 新增）

- 普通模式引导入口
- HDR 运动场景升级 + 影调升级 + 智能分区
- 两个设备均支持

### 4.12 双摄同录（前后双录 / Dual-View Video）

> 参考 PRD: Camera 4.1 - 视频前后双录 (25131, v1, Tiger, 2026-04-20)

**25131 已落地规格（基线）**:
- 分辨率: 1080P 30FPS（锁定，不可改）
- 录制形式: 预览画面录屏
- 编码: 与普通视频一致
- 防抖: 预览等级防抖
- 音频: 与普通录像一致（前后声音同时收录）
- 布局: 画中画（小窗 360×480, 3:4）+ 上下均分
- 文件: 单文件保存，命名 `VID_..._DUAL.mp4`，相册 DUAL Tag
- 后摄: 录制前可选主摄/超广，录制中不可切换
- 录制中: 截图、暂停/继续、主副互换、画中画小窗拖动
- 不支持: 4K、60FPS、HLG、HDR、滤镜、Tuning、双文件保存、录制中切换布局

**5a 项目状态**:
- **26111**: ✅ 支持（前后摄通路），具体规格待定（PRD: "26111 后续能力另行定义"）
- **26121**: ✅ 支持（前后摄通路），具体规格待定（PRD: "26111 Pro / Ultra 后续再评估"）

> 注意: PRD 撰写时 5a 仍为 26111 base/pro 命名，现 26121 = old 26111 Pro。5a 双录规格需单独 PRD 定义。
