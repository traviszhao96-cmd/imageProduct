# 自然质感人像：美颜能力升级

> 来源：[美颜能力升级需求整理文档](https://nothing-tech.sg.larksuite.com/docx/TBC9d6cwIolGWmxzBdglZjdZgxd)，revision 604，读取于 2026-07-14。

## 能力归属

- `自然质感人像 / Natural Texture Portrait` 是提升人像效果的能力族，不是单独的模式或交互入口。
- `FRT / 人像清晰度提升` 是独立的人脸细节恢复 feature，不等同于美颜。
- `美颜升级 / Beauty Upgrade` 是独立的美颜参数与效果升级 feature，本期只在照片、人像模式的前置摄像头支持。

## 美颜升级范围

现有能力继续优化参数和效果：磨皮、美白、亮眼、胡须保护，以及已有祛斑/祛痘、去眼袋和瘦脸策略。重点改善磨皮假蓬和塑料感、美白假白发灰、亮眼局部突兀，以及强档位损伤胡须和毛发纹理等问题。

新增能力：

- 匀肤（P0）：改善肤色不均、局部暗沉、色斑和脏污感，但保留毛孔、胡须、雀斑、痣、皱纹和妆容纹理。
- 肤色/人种分层（P0）：为匀肤、美白、磨皮和肤色还原选择差异化参数；不可靠时回退中性策略。
- 性别分层（P0）：男性优先保护胡须、毛发和真实肤质；女性侧重气色、均匀度和精致感；不可靠时回退中性策略。
- 年龄分层（P1）：按年龄段控制修饰强度和细节保护，不输出精确年龄；不可靠时回退中性策略。
- 脸型流畅（P2）：改善轮廓局部折线和不连续，不等同于强瘦脸，不得改变五官比例或造成背景、发际线、耳朵等区域形变。

## 效果边界

- 目标是自然、干净、接近真实状态下的好状态，避免假白、假滑、塑料感、蜡像感和面部结构变平。
- 覆盖浅、中、深肤色，保留真实肤色深度、暖度、健康气色和皮肤纹理。
- 多人场景需要确认是否逐人识别和逐人应用参数；不支持时必须定义默认策略。
- 低光、高 ISO、逆光、复杂光源、浓妆、遮挡、侧脸和大角度姿态优先保证自然度，并定义可靠性边界及回退策略。
- 地区差异通过参数配置适配，供应商无需单独识别地区。

## FL 验收口径

- 模式：`照片 / Photo`、`人像 / Portrait`。
- 摄像头：仅 `Front = ✓`；Main、UW、Tele 均为 `✗`。
- 确认角色：`SE`；效果验收由 IQA 按样张集执行，但 FL 的单一确认负责人保持 SE。
- 验证 Natural/Strong 档位、首次开启引导、参数持久化、现有参数优化、新增能力、多肤色/性别/年龄适配、多人策略及中性回退。
