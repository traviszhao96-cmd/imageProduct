# 三、 需求背景

## 产品 / 数据现状

Preset 的使用比例不断提升，也是 camera 的长期特色重点功能。但是在很多层面上仍然存在问题：

1. 与 playground 互联体验差。在2025年10月，首次推出了 nothing playground，在这个网站上用户可以轻松的分享共创出的手机配置功能，比如widget，EQ，Preset 等等。但是当前 Preset 分享和导入路径较长，依赖用户存储和上传 preset share card，体验不佳。

2. Preset 导入数量存在上限（20个）。很多用户反馈不能导入足够多的自己喜欢的 preset，体验不佳。

# 六、 功能详细说明

## Preset 导入上限提升

### 功能描述

- 在 Presset setting 界面，支持用户在 import preset 中最多导入 20 0 个 Preset，如果存储空间已满则无法继续导入

- 在 Preset setting 界面中增加关于展示 preset 界面的提示。由于内存问题，未避免过多 preset 展示导致切换卡顿，故将展示页面的数量限制到20个

    - 在 all preset 标题的下方提示“已激活预设 / Activated presets”

    - 在第20个preset的顶部增加分隔线，并在分隔线上方提示“拖动来展示预设 / Drag to show”

- 在展示列表的末尾新增预设设置界面入口。具体的交互形式待定

[https://www.figma.com/design/00upqHPBmH4ohZlewde7qE/Camera-4.0--25111-Bellsprout-?node-id=5897-47216&t=U8ZHyszXxap1ixBJ-1]()

### 异常处理

如果存储空间不足无法继续导入，或者新建 preset，提示以下 toast 提示

中文： 预设数量已达上限，请清理部分预设以添加更多

英文： Preset limit reached\. Please delete some presets to add more\.
