# 26111/26121 FL 项目约定

## 命名规范 (2026-07-08 确立)
- **照片影调 / Image Tone** = 全局 ISP 风格切换 (自然/鲜明)，替代 Photo Style
- **风格 / Style** = 用户 Toolbar 工具箱，包含 风格-滤镜、风格-调色、风格-调色盘
- **ASD / AI场景检测** = AI 语义场景检测 (绿植/舞台/天空)，不包含普通亮度/DRC判断
- **Photo EIS / PZL** = 拍照高倍防抖（后取帧），与 Video EIS 分离
- **SAT / 平滑镜头切换** 统一命名

- ASD: 所有模式所有摄像头 ✓ (owner: 影像SE)

- OIS: 按硬件推导 (26111全✗, 26121 Main/Tele ✓)
- 慢动作: 1080P/720P × 120/240 FPS, 前置 ✗
- 风格覆盖: 照片/人像/夜景/专业/运动/高像素/视频/前后双录
