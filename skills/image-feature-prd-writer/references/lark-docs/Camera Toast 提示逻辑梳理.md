# Camera Toast 提示逻辑梳理

## 一、Toast 触发原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 主动操作受阻 | 用户主动触发某功能，但因当前状态冲突无法生效 → 弹 toast | 夜景模式下长按快门触发连拍 → toast "连拍不可用" |
| 功能被自动关闭 | 用户开启某功能后，另一功能被自动关闭 → 弹 toast 告知被关闭的功能 | 开启 HDR → 自动关闭滤镜 → toast "滤镜已关闭" |
| 静默不可用 | 功能因当前状态不可用，但用户没有操作 → 不弹 toast | 切换模式后连拍按钮置灰，不弹 toast |

## 二、功能互斥矩阵与 Toast 规则

### 2.1 拍照模式

| 当前模式 | 触发操作 | 是否冲突 | Toast 行为 |
|----------|----------|----------|------------|
| 人像（后置） | 长按快门（连拍） | 冲突 | 弹 toast："连拍不可用" ❌ 当前缺失 |
| 夜景（后置） | 长按快门（连拍） | 冲突 | 弹 toast："连拍不可用" ❌ 当前缺失 |
| 高像素模式 | 长按快门（连拍） | 冲突 | 弹 toast："连拍不可用" |
| 运动模式 | 长按快门（连拍） | 待确认 | — |
| 人像（后置） | 开启闪光灯 | 冲突 | 弹 toast："人像模式下闪光灯不可用" |
| 夜景 | 开启闪光灯 | 冲突 | 弹 toast："夜景模式下闪光灯不可用" |
| 人像（后置） | 开启 HDR | 待确认 | — |
| 夜景 | 开启 HDR | 冲突 | 待确认 toast 行为 |

### 2.2 HDR / 滤镜 / 调色

| 当前状态 | 触发操作 | 是否冲突 | Toast 行为 |
|----------|----------|----------|------------|
| 滤镜已开启 | 开启 HDR（拍照） | 冲突 | 弹 toast："HDR 已开启，滤镜已关闭" 或 "滤镜已关闭" |
| HDR 已开启 | 选择滤镜 | 冲突 | 弹 toast："HDR 开启时不支持滤镜" 或 "滤镜不可用" |
| 调色已开启 | 开启 HDR（拍照） | 冲突 | 弹 toast："HDR 已开启，调色已关闭" 或 "调色已关闭" |
| HDR 已开启 | 调整调色 | 冲突 | 弹 toast："HDR 开启时不支持调色" 或 "调色不可用" |

### 2.3 视频 HDR

| 当前状态 | 触发操作 | 是否冲突 | Toast 行为 |
|----------|----------|----------|------------|
| 滤镜已开启 | 开启 HDR 视频 | 冲突 | 弹 toast："滤镜已关闭" 或 "HDR 视频已开启，滤镜已关闭" |
| 调色已开启 | 开启 HDR 视频 | 冲突 | 弹 toast："调色已关闭" 或 "HDR 视频已开启，调色已关闭" |
| HDR 视频已开启 | 选择滤镜 | 冲突 | 弹 toast："滤镜不可用" |
| HDR 视频已开启 | 调整调色 | 冲突 | 弹 toast："调色不可用" |
| HDR 视频开启中 | 滤镜/调色关闭 HDR | 被关闭 | 弹 toast："HDR 视频已关闭" ❌ 当前缺失 |

## 三、当前 Toast 缺失问题

### 问题 1：人像模式后置 → 连拍无 toast

- **操作：** 人像模式（后置）+ 长按快门触发连拍
- **预期：** 弹 toast "连拍不可用"
- **现状：** 无 toast，连拍静默不生效

### 问题 2：夜景模式后置 → 连拍无 toast

- **操作：** 夜景模式（后置）+ 长按快门触发连拍
- **预期：** 弹 toast "连拍不可用"
- **现状：** 无 toast，连拍静默不生效

### 问题 3：HDR 视频被 filter/tuning 关闭 → 无 toast

- **场景 A：** HDR 视频开启 → 用户选择滤镜/调色 → HDR 视频被自动关闭
- **场景 B：** 滤镜/调色已开启 → 用户开启 HDR 视频 → 滤镜/调色被关闭
- **现状：** 两个方向都没有 toast 提示
