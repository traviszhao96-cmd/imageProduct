二、需求背景
产品现状
当前 Album 页面仅支持静态展示，用户无法调整图集顺序，图集完全按照字母顺序显示
对于希望自定义页面布局的用户来说，操作受限，页面灵活性不足
Album 全都使用了大图设计，占用较大空间，更多 album 无法正常显示

用户场景
用户希望将常用图集拖动到更靠前的位置，方便快速访问
用户对当前的界面有一定的使用习惯，不希望直接修改大图布局
用户希望将低频图集移动到小图区域，减少视觉占用
用户希望直接通过拖拽完成调整，而不是进入额外编辑模式
用户可能会有很多的图集，完全通过拖动来编辑要跨越很远范围

三、需求目标
补齐 Album 页面的拖拽整理能力
支持用户自定义图集顺序
支持用户在大图区域和小图区域之间自由移动图集
统一 Album 页面图集编辑交互规范

四、需求范围
单个图集长按并滑动，进入拖拽状态
所有图集支持拖拽排序
所有图集支持在大图区域和小图区域之间移动
拖拽态下显示明显分割线
拖拽过程中支持自动滚动
松手后立即保存排序结果
图集顺序编辑页面（更多 → Edit）

六、功能说明
1. Albums 页面改版
为提升 Album 页面的信息效率和可操作性，本次对页面布局进行改版，将图集展示拆分为大图区域与小图区域。
默认大图图集：Camera / Videos / Screenshots / Favourite 共 4 个
默认小图图集为其余所有图集
「更多」区域（折叠在小图区域下方）：Map（第一）、Recent（第二），及用户自定义相册
以上仅为默认布局，用户后续可自由调整
所有图集均支持排序
所有图集均支持在大图区域与小图区域之间移动
大图区域无固定数量上限，最终展示结果以用户调整后的布局为准

2. 长按拖拽排序（不进编辑态）
为兼容现有 Album settings 能力并新增图集拖拽排序，长按操作需先进入意图识别，再根据用户后续行为判断触发功能。
2.1 触发条件
用户在 Album 页面长按图集卡片超过 500ms 后，触发一次震动反馈
震动反馈表示系统已识别长按手势，但此时不立即进入具体功能
在震动反馈后，系统根据用户是否发生滑动以及是否释放手指，判断用户操作意图
2.2 交互规则
若用户长按超过 500ms 后未发生滑动并在静止状态下释放手指 → 触发 Album settings（修改名称、删除等）
若用户在震动反馈后滑动距离超过 10dp → 触发图集拖拽排序
2.3 拖拽排序状态
进入拖拽排序后，页面进入图集重排序状态
列表中展示上下分割线，提示可插入位置；跨越分割线时提供位置变化反馈
拖拽过程中，所有图集统一切换为中等尺寸，滑动不改变大小
支持自动滚动
松手后立即保存排序结果
2.4 状态定义（途径一）


状态

触发条件

表现

普通态

默认

正常浏览状态，正常展示图集

长按识别中

用户长按但未满 500ms

仅保留按压反馈，未进入任何功能

拖拽态

长按超过 500ms + 滑动距离 > 10dp

图集浮起、显示分割线、所有图集切换为中等尺寸

同区排序态

拖拽态下在原区域内拖动

同区域图集让位，显示落位预览

跨区移动态

拖入另一目标区域

目标区域接纳并重排，跨越分割线时有明确反馈

落位完成态

松手完成排序/移动

保存新布局，图集恢复目标区域正式尺寸（大/小图）

回弹态

无效落位或中断

图集回弹到原位置，不弹 toast

2.5 尺寸变化规则
拖拽过程中，所有图集统一显示为中等尺寸图（不区分大图/小图），滑动不会改变图集大小
松手落位后，按目标区域的正式尺寸显示：大图区域 → 大图，小图区域 → 小图

2.6 保存与退出
松手成功落位后，立即保存最新布局；若位置无变化，保持原顺序
保存失败 → 回退到上一次成功状态
拖拽无效或异常中断 → 仅执行回弹动画，不弹 toast

3. Edit 编辑模式
在 Album 页面右上角「更多」菜单中新增 Edit 入口。长按拖拽满足偶发微调，Edit 满足深度整理。

3.1 入口
Album 页面 → 更多（⋮） → Edit

3.2 编辑模式交互
点击 Edit → 进入编辑模式，所有图集直接可拖拽（无需长按），显示为中等尺寸
每个图集右上角出现箭头按钮，用于一键切换大图/小图区域
图集卡片显示抖动动画或拖拽手柄（≡），提示可拖拽
顶部工具栏：Done（保存退出）
点击 Done → 保存当前布局，退出编辑模式
系统返回键 / 手势返回 → 弹出确认框「是否保存更改？」
编辑模式下无超时自动保存（与长按松手即存区分）
若大图区域或小图区域为空（无任何图集），对应区域显示占位图（灰色虚线边框，尺寸与中等图集一致），提示用户可将图集拖入该区域

3.3 箭头切换规则
大图区域图集 → 绿色向上箭头 ↑ → 点击切换为小图，移入小图区域
小图区域图集 → 红色向下箭头 ↓ → 点击切换为大图，移入大图区域
箭头切换不改变同区域内的排序位置，仅切换区域；切换后箭头颜色同步翻转

3.4 编辑模式状态定义
编辑模式状态：
编辑-普通态：编辑模式下默认状态，从「更多」进入
编辑-拖拽态：编辑模式下拖拽图集，所有图集为中等尺寸
编辑-箭头切换：点击箭头切换大图/小图
编辑-保存退出：点击 Done 保存并退出
编辑-放弃退出：返回且放弃更改

4. 保存与退出（统一规则）
以下规则适用于途径一和途径二：
松手成功落位 / 点击 Done → 立即保存最新布局
若位置无变化，保持原顺序
保存失败 → 回退到上一次成功状态
拖拽无效或异常中断 → 仅执行回弹动画，不弹 toast

八、非功能需求
性能
长按进入拖拽态响应自然，无明显延迟
拖拽过程中保持流畅，不出现明显卡顿
同区域重排、跨区域移动、自动滚动过程需平滑

兼容性
适配横竖屏
适配不同屏幕尺寸
适配深色/浅色主题
