# 1. 需求背景与目标

## 战略对齐

本需求承接 <cite doc-id="VPYHwL7vOiOUYEkS0nulJXJIg3B" file-type="wiki" title="26111/26121 视频需求 Overview" type="doc"></cite> 中的「创作玩法」方向，服务于具备基础拍摄能力、会用手机进行日常记录和轻量创作，并希望通过不同视角丰富表达的用户。

## 核心问题

在演出、旅行、朋友聚会、家庭与宠物互动等场景中，拍摄者往往既希望记录眼前发生的事情，也希望保留自己作为参与者的反应。单路视频只能选择其中一个视角，拍摄过程中切换摄像头又会破坏内容连续性。

25131 已经完成前后摄同步录制的基础能力，但以独立模式承载，进入成本较高，小窗调整与录制中的视角控制也不够完整。Camera 5.1 需要把双录变成标准视频流程中的一种创作能力。

## 需求定位

前后双录不是专业视频模式，而是标准视频模式中的组合拍摄玩法。它的核心价值是同时保留「眼前内容」与「拍摄者反应」，并允许用户在录制前组织布局、在录制过程中调整画面主次，而不打断当前记录。

## 目标结果

用户能够在标准视频模式中快速开启双录，选择画中画或均分布局，调整小窗大小与位置，并在录制过程中交换前后画面的主次。录制过程连续，最终文件可正常播放、分享和编辑。

# 2. 需求定义

## 2.1 需求组成与适用范围

- 适用于 26111、26121 的标准视频模式。
- 双录作为视频模式内的开关存在，不再提供独立拍摄模式。
- 支持画中画与上下均分两种布局，默认使用画中画。
- 默认生成合并视频；用户可在设置中选择分别保存前、后摄视频。
- 基础输出规格为 1080p 30fps SDR。

## 2.2 入口、状态与记忆

- 录制前，用户从标准视频模式的 Preset 面板顶部「前后双录」选项开启或关闭 Dual view。
- 关闭状态下，顶部不显示 Dual view 状态；开启后，顶部显示状态入口，并提供画中画 / 均分布局切换入口。
- 菜单入口与顶部状态入口使用同一状态源，任一入口关闭后，双录预览退出并恢复普通视频。
- 录制中不允许开启或关闭双录；不提供可执行该操作的入口。
- 双录开关遵循[相机五分钟记忆规则](https://nothing-tech.sg.larksuite.com/wiki/Yi5iwRJSPit8LfkeT2ClUbJlgOd)：短时间切换到其他模式再返回视频时保持开启；超过五分钟后恢复关闭。
- 布局与小窗尺寸永久保留用户上次选择；小窗位置不记忆，每次进入时回到默认位置。

## 2.3 布局切换

- 画中画为默认布局，前置画面默认位于右上角小窗；上下均分时，两路画面各占一半取景区域。
- 仅录制前允许在画中画与均分之间切换；录制中隐藏布局切换入口。
- 布局切换采用即时过渡，不增加高斯模糊或其他遮挡画面的转场。
- 布局切换不重置当前 3A 状态。

## 2.4 小窗大小与位置

- **比例与尺寸：**小窗保持固定 **4:3** 比例，前、后摄画面等比填满并居中裁切，不拉伸、不留黑边。提供两档尺寸：小档为可用取景宽度的 35%，大档为 50%；首次进入使用小档。
- **调整大小：**不显示缩放手柄；用户可通过小窗左下角的隐形热区拖动调整大小，松手后以动画吸附至更接近的一档。
- **移动与吸附：**录制前和录制中均可拖动小窗。拖动过程中小窗跟随手指；松手后以吸附动画移动至最近的可用边缘或屏幕纵向中心位置，并提供磁吸触觉反馈。
- **界面避让：**小窗接近快门、变焦或其他操作区域时，相关 UI 以动画方式避让；小窗移开后恢复原位，保证操作入口始终可用。
- **输出边界：**合并保存模式下，录制中的小窗移动、换档与吸附动画同步写入最终视频，输出结果与录制时的布局变化一致；隐形热区、触觉反馈及周围 UI 避让等控制反馈仅存在于预览界面，不写入最终视频。
- **设计参数：**热区、边距、吸附位置、动画时长与曲线以正式设计稿为准。

## 2.5 前后画面互换

- 录制前和录制中均可通过与普通视频一致的前后摄切换按钮，交换前、后画面的位置和主次。
- 画中画布局中，主画面与小窗互换；均分布局中，上下画面互换。
- 互换采用即时切换，不中断录制，也不在最终视频中加入模糊动画。
- 前、后摄各自维持已有的对焦、曝光与白平衡等 3A 状态；画面互换不重新触发或重置 3A，也不在两路摄像头之间继承参数。用户需要改变结果时再主动调节。
- 分别保存开启时，互换只改变预览中的前、后画面位置，不改变前、后摄独立文件的身份或内容来源。

## 2.6 后置镜头与变焦

| **项目** | **26111** | **26121** |
|-|-|-|
| 本期后置镜头范围 | 超广角、主摄（录制前选择） | 超广角、主摄、长焦 |
| 变焦档位 | 0.6× 、1× - 2× - 4× | 0.6× - 1× - 2× - 3.5× - 7× |
| 变焦范围 | UW：0.6× - 2×；主摄：1× - 8× | 0.6× - 20× |
| 录制中变焦 | 支持；范围随起录镜头锁定 | 支持（SAT） |

**26111 当前范围边界：**本期采用录制前硬切方案，不支持录制中的 SAT。录制前，用户可在预览阶段选择超广角或主摄；开始录制后固定所选后置物理摄像头，录制中不发生跨摄像头切换。以 UW 起录时，0.6×–2× 全程使用 UW 数字变焦，不切换至主摄；以主摄起录时，保持 1×–8× 变焦范围。

## 2.7 对焦、曝光与人脸反馈

- 画中画布局下，仅主画面响应点击对焦与曝光调节；均分布局下，两侧画面分别响应对应区域操作。
- 前、后摄各自维持已有的 3A 状态；布局切换及前后画面互换不重新触发或重置 3A，也不在两路摄像头之间继承参数。
- 双录预览中隐藏人脸框，但保留人脸识别及其对 3A 的内部作用。

## 2.8 文件保存

**合并保存。**默认生成一个包含当前画中画或均分布局的视频文件，沿用 DUAL 文件名标识与相册 Tag。暂停、继续和录制中拍照均作用于当前合并画面。

**分别保存。**Camera settings 的 Video 区域提供「Save Dual-View separately」开关，默认关闭。开启后不再生成合并视频；录制结束仅生成两个时长一致的独立文件：

- 后摄：`VID_yyyymmdd_hhmmss_DUAL_REAR.mp4`。
- 前摄：`VID_yyyymmdd_hhmmss_DUAL_FRONT.mp4`。
- 后摄文件保留当前镜头与变焦结果，前摄文件保留前置画面；两个文件均不包含画中画 / 均分合成或预览 UI。
- 两个文件使用相同时间戳，时长一致，并均包含完整音轨。
- 保存方式只允许在录制前配置；录制中不可切换。

分别保存开启时 Style 不可用。录制异常与中断沿用普通视频逻辑。分开保存的视频在相册中仍应识别 `DUAL` 标签。

## 2.9 兼容范围

| **能力** | **关系** | **双录开启后的行为** |
|-|-|-|
| 4K、60fps、HDR、Log | 不兼容 | 锁定为 1080p 30fps SDR；相关规格不可调。 |
| Style | 兼容 | 合并保存时，前后两路同步应用同一 Style；分别保存开启时**不可用**。 |
| EV、WB、AE Lock | 不兼容 | 双录开启后不提供相关入口。 |
| 自拍镜像 | 双录固定开启 | 双录开启期间，从双录进入 Camera settings 时，「自拍镜像」开关固定显示为开启并置灰，不允许修改；前置预览以及合并保存、分别保存中的前置画面均按镜像结果输出。退出双录后，该设置恢复普通相机中的可编辑状态。 |
| 慢动作、延时摄影等其他模式 | 模式隔离 | 仅标准视频模式提供 Dual view。 |

## 2.10 Preset

Dual view 不再作为独立拍摄模式出现在 Preset 中。标准视频模式的 Preset 面板顶部新增「前后双录」选项；未选择时沿用普通视频 Preset 内容，选择后隐藏下方镜头、焦距、分辨率和 HDR 选项，并新增布局选项。布局选项提供画中画与上下均分。

# 3. 验收标准

本章只定义产品验收结果；具体测试场景、方法与质量阈值由软测与 IQA 在测试方案中展开。

- **入口与状态正确：**视频 Preset 顶部提供「前后双录」选项；选择状态、顶部状态和五分钟记忆符合第 2.2 节定义；选择后隐藏镜头、焦距和分辨率选项，并显示布局选项。
- **布局与小窗可用：**画中画 / 均分、35% / 50% 两档尺寸、隐形缩放热区、拖动吸附、触觉反馈与 UI 避让符合正式设计；录制中允许移动和换档，但不允许切换布局。
- **录制连续：**前后画面互换、移动小窗和调整大小不结束录制，不出现黑帧、卡死、持续掉帧、崩溃或文件损坏。
- **状态保持正确：**布局切换和前后画面互换不重新触发或重置 3A，前、后摄各自维持已有状态且不相互继承参数；隐藏人脸框时，人脸识别能力仍正常工作。
- **镜头与变焦正确：**各机型本期镜头范围和变焦档位符合第 2.6 节；26111 录制前可在 UW 与主摄之间选择，UW 起录时支持 0.6×–2×，主摄起录时支持 1×–8×；开始录制后固定所选后置物理摄像头，录制中不发生跨摄像头切换。
- **文件输出正确：**合并保存时，最终视频包含录制中的小窗移动、换档与吸附动画，布局变化与预览一致；分别保存开启时，仅生成前、后两个时长一致、音轨完整且不含合成布局或预览 UI 的可播放文件，不保留合并视频。
- **兼容边界正确：**双录锁定 1080p 30fps SDR；自拍镜像、Style 与 EV / WB / AE Lock 的可用性符合第 2.9 节，分别保存行为符合第 2.8 节。
- **质量达标：**双路画面同步，录制过程中不出现非用户操作导致的异常曝光 / 色温跳变、持续震荡、明显音画不同步或不可恢复的预览异常。
