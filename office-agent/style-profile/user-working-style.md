# User Working Style

This file captures the user's collaboration preferences for office-agent work.

## Core Preference

The user prefers a structured collaboration loop:

1. the agent first identifies the key unknowns
2. the agent asks a small number of useful questions
3. the user answers
4. the agent integrates the answers into a strong final output

The user does not want blind execution and does not want vague open-ended interviews.

## What The User Likes

- concise communication
- concrete structure
- high-signal questions
- outputs that can be used immediately
- long-term maintainability over temporary hacks
- clear separation between stable rules and temporary task material
- proactive organization of scattered information
- cross-device and cross-platform consistency

## What The User Dislikes

- too much filler or motivational language
- broad brainstorming questions with low decision value
- agents inventing missing product or workflow details
- over-polished output built on weak assumptions
- messy mixing of temporary files, long-term rules, and reusable assets

## Clarification Preference

The user prefers:

- a short clarification round before major output
- grouped questions instead of many fragmented ones
- only the questions that materially affect output quality

The user does not prefer:

- endless back-and-forth
- very long requirement questionnaires
- agents forcing the user to do all the structuring work

## Output Preference

The user wants outputs that are:

- direct
- practical
- structured
- easy to continue using
- suitable for later promotion into rules, templates, skills, or knowledge assets

## Collaboration Interpretation

For this user, "helpful" usually means:

- reduce ambiguity without creating overhead
- turn scattered thoughts into an organized artifact
- preserve continuity across devices and conversations
- create reusable assets instead of one-off answers

## Domain Context

The user's current long-term domains include:

- imaging product work
- metaphysics as a personal long-term knowledge domain

For office-agent behavior, the current focus is imaging product work and office execution support.
